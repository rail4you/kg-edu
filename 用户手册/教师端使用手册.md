## 第一章 系统概述与登录

### 1.1 系统简介

智课云枢教师端是为教师提供的一站式教学管理平台，支持课程管理、知识点管理、AI 辅助教学、学习数据分析、考试组卷、作业批改、微专业编排等功能。

### 1.2 登录系统

1. 打开浏览器访问系统地址
2. 输入用户名 `wang`、密码 `wwq123456`
3. 点击 **登录**

> 提示：登录页截图待补充。

### 1.3 界面布局

- **左侧导航栏**：所有功能模块菜单（可折叠）
- **顶部工具栏**：菜单搜索、通知、用户头像
- **主内容区**：当前页面内容

### 1.4 退出登录

点击右上角头像 → **退出登录**

## 第三章 AI 工作台

### 3.1 AI 智能体助手

![AI 智能体助手](images/teacher/03-ai-assistant.png)

**功能描述**：AI 智能体助手提供智能对话服务，解答教学问题。

**页面说明**：
- 左侧：会话历史列表
- 右侧：聊天主界面
- 底部：输入框
- 操作：新建会话、删除会话、点赞、点踩、复制

**操作步骤**：
1. 进入 AI 智能体助手页面
2. 点击 **新建会话**
3. 在输入框输入问题
4. 点击发送，AI 生成回复
5. 可对回复进行点赞、点踩反馈

### 3.2 AI 生成试题

![AI 生成试题](images/teacher/04-ai-exercise.png)

**功能描述**：利用 AI 自动生成练习题。

**页面说明**：
- 顶部课程下拉框
- AI 练习历史列表
- 题目类型筛选

**操作步骤**：
1. 选择目标课程
2. 选择题目类型（单选/多选/填空/简答）
3. 选择知识点范围
4. 设置题目数量、难度
5. 点击 **生成**
6. 在生成的题目中编辑、调整
7. 保存到题库

### 3.3 AI 文件管理

![AI 文件](images/teacher/05-ai-file.png)

**功能描述**：管理 AI 生成的文件内容。

**页面说明**：
- 卡片视图 / 表格视图切换
- 课程选择器
- 搜索功能

**操作步骤**：
1. 选择课程
2. 使用搜索框查找文件
3. 切换视图
4. 点击文件查看或下载

### 3.4 AI 命令中心

![AI 命令中心](images/teacher/06-ai-command.png)

**功能描述**：管理 AI 命令模板，定制个性化 AI 助手指令。

**操作步骤**：
1. 进入命令中心
2. 浏览已有命令模板
3. 点击 **创建新命令** 添加模板
4. 编辑命令名称、描述、prompt 模板
5. 保存后可在 AI 对话中调用

### 3.5 AI 备课 / 课件

**入口**：左侧菜单 → AI 工作台 → AI 备课

**功能描述**：AI 辅助生成课程课件。

**操作步骤**：
1. 选择课程和章节
2. 输入教学目标
3. AI 自动生成课件大纲
4. 编辑调整内容
5. 导出为 PPT/PDF

### 3.6 AI 备课（详细）

**功能描述**：基于教学大纲和知识点，AI 自动生成结构化课件内容。

**页面说明**：
- 左侧：教学目标输入
- 中部：AI 生成的内容
- 右侧：参考资料、相关知识点

**操作步骤**：

#### 生成课件

1. 选择目标课程
2. 选择章节
3. 输入教学目标（建议详细）
4. 选择课件类型：讲义 / PPT 大纲 / 教学设计
5. 选择生成深度：简要 / 详细 / 完整
6. 点击 **生成**
7. 等待 AI 生成（通常 10-30 秒）

#### 编辑课件

1. 生成后进入编辑器
2. 修改标题、内容
3. 调整章节结构
4. 添加图片、表格
5. 引用知识点（自动关联）

#### 导出

1. 点击 **导出**
2. 选择格式：PPT / PDF / Word / Markdown
3. 选择模板
4. 下载

### 3.7 AI 课件

**功能描述**：管理与 AI 备课生成的课件文件。

**操作步骤**：
1. 进入 AI 课件页面
2. 浏览已生成的课件列表
3. 查看课件预览
4. 点击 **编辑** 进入编辑模式
5. 点击 **分享** 给学生
6. 点击 **删除** 移除课件

### 3.8 AI 题库

**功能描述**：AI 智能管理题库，支持智能检索、相似题推荐、自动组卷。

**操作步骤**：

#### AI 智能检索

1. 进入 AI 题库
2. 输入检索条件：
   - 知识点
   - 题型
   - 难度
   - 关键词
3. AI 检索并返回结果

#### 相似题推荐

1. 选中一道题
2. 点击 **相似题**
3. AI 生成相似题目（考察相同知识点）

#### 自动组卷

1. 点击 **AI 组卷**
2. 设置组卷参数：
   - 题型分布
   - 知识点覆盖
   - 难度系数
   - 总分
3. 点击 **生成**
4. 查看预览
5. 保存到试卷

### 3.9 AI 讨论

**功能描述**：AI 总结学生讨论、提取关键问题、生成回复建议。

**操作步骤**：

#### AI 总结

1. 选择讨论主题
2. 点击 **AI 总结**
3. 查看自动生成的：
   - 关键观点
   - 未解决问题
   - 学生认知误区
   - 优秀回答

#### AI 生成回复

1. 在讨论中点击 **AI 辅助**
2. 选择回复风格：详细 / 简洁 / 启发式
3. AI 生成回复草稿
4. 教师审核修改
5. 发送

### 3.10 AI 智能体（高级）

**入口**：AI 工作台 → 智能体

**功能描述**：可定制的 AI 助手，配置特定领域知识。

**操作步骤**：
1. 创建智能体
2. 配置：
   - 名称、头像
   - 角色描述
   - 知识库
   - 工具调用
3. 保存后在对话中使用

## 第五章 知识点管理

### 5.1 知识点管理

![知识点管理](images/teacher/11-knowledge-management.png)

**功能描述**：管理知识点，支持多级分类（主题→知识单元→知识点）。

**页面说明**：
- 左侧：课程选择
- 右侧：树形结构
- 顶部统计：主题数、知识单元数、知识点数
- 操作：导入、导出、AI 智能导入

**操作步骤**：

#### 创建主题

1. 选择课程
2. 点击 **创建主题**
3. 填写主题名称、描述
4. 保存

#### 创建知识单元

1. 展开主题
2. 点击 **+** 添加知识单元
3. 填写信息
4. 保存

#### 创建知识点

1. 展开知识单元
2. 点击 **+** 添加知识点
3. 填写名称、描述、认知层级
4. 保存

#### 批量导入

1. 点击 **导入**
2. 下载模板
3. 按模板填写
4. 上传文件
5. 系统解析预览
6. 确认导入

#### AI 智能导入

1. 点击 **AI 智能导入**
2. 输入课程大纲或粘贴内容
3. AI 自动分析生成知识点结构
4. 校对调整后保存

### 5.2 知识关系管理

3. 点击 **添加关系**
4. 选择源知识点

7. 保存

#### 删除关系

2. 点击 **删除**
3. 确认

**操作步骤**：

### 5.4 知识点资源

## 第六章 知识图谱

### 6.1 课程图谱

![课程图谱](images/teacher/13-graph-course.png)

**功能描述**：可视化展示课程的知识图谱。

**操作步骤**：
1. 选择课程
2. 系统自动生成图谱
3. 鼠标拖拽、缩放查看
4. 点击节点查看知识点详情
5. 可导出图谱图片

### 6.2 知识图谱 / 树图

**入口**：图谱 → 树图

**功能描述**：以树形结构展示知识点层级关系。

**页面说明**：
- 根节点：课程
- 二级节点：主题
- 三级节点：知识单元
- 叶节点：知识点
- 节点颜色按主题分类

**操作步骤**：
1. 切换到 **树图** 标签
2. 选择课程
3. 点击节点展开/折叠
4. 拖拽节点调整布局
5. 右键节点操作：
   - 添加子节点
   - 编辑
   - 删除
   - 关联资源

**应用场景**：
- 课程结构梳理
- 知识点查重
- 教学大纲设计

### 6.3 知识图谱 / 环图

**入口**：图谱 → 环图

**功能描述**：以环形布局展示知识点。

**页面说明**：
- 中心：课程或主题
- 环形：知识单元
- 外环：知识点
- 颜色编码：按主题或章节

**操作步骤**：
1. 切换到 **环图** 标签
2. 选择课程
3. 鼠标悬停查看节点信息
4. 点击节点查看详情
5. 滚轮缩放
6. 双击节点聚焦

### 6.4 知识图谱 / 布局图

**入口**：图谱 → 布局图

**功能描述**：自定义布局展示，支持多种布局算法。

**布局算法**：
- 力导向（默认）
- 层次布局
- 网格布局
- 环形布局
- 辐射布局

**操作步骤**：
1. 切换到 **布局图** 标签
2. 选择布局算法
3. 选择课程
4. 调整参数：
   - 节点间距
   - 连线粗细
   - 节点大小
5. 导出图片或 PDF

### 6.5 问题图谱

**入口**：图谱 → 问题图谱

**功能描述**：以习题为中心的关联图。

**页面说明**：
- 中心节点：习题
- 周围节点：考察的知识点
- 节点大小：题目分值
- 颜色：题型分类

**操作步骤**：
1. 切换到 **问题图谱** 标签
2. 选择课程或题库
3. 选择筛选条件：题型、难度、知识点
4. 浏览习题节点
5. 点击习题查看题目
6. 点击知识点查看详情
7. 分析考察范围

### 6.6 能力图谱

**功能描述**：展示能力目标与知识点的映射。

**页面说明**：
- 主节点：能力目标
- 子节点：支撑该能力的知识点
- 关联线：能力-知识点映射
- 颜色：能力分类

**操作步骤**：
1. 切换到 **能力图谱** 标签
2. 选择能力维度（专业能力/方法能力/社会能力）
3. 浏览能力节点
4. 点击能力节点查看：
   - 能力描述
   - 培养目标
   - 关联知识点
   - 培养方案
5. 编辑能力-知识点关联
6. 导出能力图谱

### 6.7 能力管理

**入口**：能力管理

**功能描述**：管理能力分类、定义、关联知识点。

**页面说明**：
- 左侧：能力分类树
- 右侧：能力项列表
- 操作：创建、编辑、删除、关联

**操作步骤**：

#### 创建能力分类

1. 点击 **新建分类**
2. 输入分类名称（如"专业核心能力"）
3. 输入描述
4. 选择父分类（如有）
