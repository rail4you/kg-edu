### 第一章 概述与登录

#### 1.1 系统简介

课堂星是融合知识图谱与人工智能技术的智慧教学平台。学生端围绕「课程」组织学习内容，提供课程概述、课程视频、认知目标、教学资源、知识图谱、学习推荐、互动课堂、考试、实验、邮件问答等功能。

#### 1.2 登录系统

1. 打开浏览器访问学校/机构分配的访问地址。
2. 在登录首页选择 **学生登录**。
3. 输入学校/机构分配的用户名和密码。
4. 若账号属于多个组织（租户），会弹出「选择组织」窗口，选择所在学校/机构后进入首页。

> 📷 学生登录表单：
>
> ![学生登录表单](images/student/s_00_login.png)

> 📷 选择组织：
>
> ![选择组织](images/student/s_00b_select_org.png)

#### 1.3 首页布局

登录成功后进入系统首页，自上而下分为：

- **顶部导航**：首页、课程、微专业、教学资源库、示范教学包、数字教材、合作单位、关于我们。
- **精品课程轮播**：展示重点推荐课程（如「设计表现基础」），可左右切换。
- **快捷导航**：智慧课程、微专业、数字教材、教学资源库、示范教学包、关于我们。
- **学科分类**：按学科（理学、工学、艺术学、哲学等）分类展示课程入口。

> 📷 系统首页：
>
> ![系统首页](images/student/s_01_home.png)

#### 1.4 退出登录

点击页面右上角用户菜单，选择 **退出登录** 返回登录首页。

### 第十章 常见问题

#### Q1：登录后提示选择组织怎么办？

说明该账号属于多个学校/机构，请选择你所在的学校（租户）后进入。

#### Q2：课程列表里显示「可选课」和「已选课」有什么区别？

「可选课」表示你尚未加入该课程，点击进入课程首页后按提示选课/加入学习；「已选课」表示已加入，可直接进入学习。

#### Q3：进入课程学习区后应该先看什么？

建议按左侧导航顺序学习：先看「课程概述」了解课程信息，再看「图谱总览」建立知识框架，然后按「课程视频 → 认知目标 → 教学资源 → 学习推荐」逐步学习。

#### Q4：如何参加考试？

进入「考试系统」页面，在考试列表点击 **继续考试** 开始答题，完成后提交即可查看成绩。

#### Q5：找不到某个学习内容？

部分内容需要教师发布后才对学生可见。如果页面显示为空，请先确认教师是否已发布相关内容，或切换其他课程查看。

### 第十三章 常见问题

#### Q1：登录后没有看到某个菜单？

教师端菜单按功能分组展示，请先在模块选择页确认进入的是「智慧课程」还是「微专业」模块；微专业相关菜单仅在「微专业」模块中。

#### Q2：部分页面按钮为灰色不可点击（如分组管理、分组任务）？

这些功能需要先在上方选择课程后才会启用，请先选择目标课程。

#### Q3：如何快速找到某个功能页面？

使用左侧导航顶部的菜单搜索框（快捷键 `⌘K` / `Ctrl+K`），输入功能名称即可搜索；常用页面可加入「收藏夹」，方便下次快速访问。

#### Q4：如何修改登录密码？

进入「系统设置」页面，点击 **修改密码**，输入当前密码与新密码即可。

#### Q5：学生端能看到我配置的图谱和资源吗？

学生在学习区通过「图谱总览」「专业知识图谱」「教学资源」等页面查看教师配置的内容，请确保内容已关联到对应课程/章节。

### 第一章 概述与登录

#### 1.1 系统简介

课堂星是融合知识图谱与人工智能技术的智慧教学平台。管理员使用手册面向租户管理员（学校/机构管理员），介绍「管理平台」中各页面的功能。

管理平台入口为 `/admin/dashboard`（登录后自动进入）。管理员负责本组织内的管理员、教师、学生账号管理，以及班级、小组的组织管理。

#### 1.2 管理员的权限范围

管理员与超级管理员使用同一套管理平台，管理员可见的菜单如下：

| 菜单 | 管理员 | 超级管理员 |
|------|:---:|:---:|
| 管理控制台 | ✅ | ✅ |
| 租户管理 | ❌ | ✅ |
| API Key 配置 | ❌ | ✅ |
| 管理员管理 | ✅ | ✅ |
| 教师管理 | ✅ | ✅ |
| 学生管理 | ✅ | ✅ |
| 班级管理 | ✅ | ✅ |
| 小组管理 | ✅ | ✅ |
| 权限管理 | ✅ | ✅ |
| 系统状态 | ✅ | ✅ |
| 系统日志 | ✅ | ✅ |

> 租户管理、API Key 配置仅超级管理员可见，普通管理员访问会提示「权限不足」。

#### 1.3 登录系统

1. 打开浏览器访问学校/机构分配的访问地址。
2. 在登录首页选择 **管理员登录**。
3. 输入学校/机构分配的用户名和密码。
4. 登录成功后自动进入 **管理控制台**。

> 管理员登录后即绑定所在组织，各管理页面展示的是本组织内的数据。

> 📷 登录首页（角色选择）：
>
> ![登录首页-角色选择](images/admin/a_00_login.png)

> 📷 管理员登录表单：

> ![管理员登录表单](images/admin/a_01_login_form.png)

#### 1.4 界面布局

管理平台页面自上而下、自左而右分为四个区域：

- **顶部栏**：左侧为平台标识与「智慧教学系统 · 管理平台」标题（点击可返回管理控制台）；右侧为通知铃铛和用户头像菜单。
- **左侧导航**：列出当前角色可见的所有功能模块。

1. 点击顶部栏右侧的用户头像。
2. 在弹出的抽屉面板中：
   - 点击 **修改密码**，依次输入当前密码、新密码（至少 6 位）、确认新密码，点击 **确认修改**。

> ![管理员管理](images/admin/a_03_admins.png)

**入口**：左侧导航 → **管理员管理**。

**功能描述**：管理本组织内的管理员账号（`admin` 角色），支持添加、编辑、删除、查看详情与批量导入。

**页面说明**：

- 顶部信息栏显示「管理组织: 组织名称」，右侧显示管理员数量。
- 表格字段：**用户ID**、**姓名**（带头像）、**邮箱**、**手机号**、**学校/机构**。
- 支持按用户ID、姓名、邮箱、学校/机构关键词搜索。

#### 3.1 添加管理员

**操作步骤**：

1. 点击右上角 **添加管理员**。
2. 在弹出的表单中填写：
   - **用户头像**：可选，点击上传图片。
   - **用户ID**（必填）：登录账号，需唯一。
   - **姓名**（必填）。
   - **邮箱**（可选，格式需正确）。
   - **手机号**（可选）。
   - **学校/机构**（可选）。
   - **密码**（必填，至少 6 位）与 **确认密码**。
3. 点击 **创建管理员**。

> 常见提示：用户ID 重复会提示「用户ID已存在」；邮箱格式错误会提示「邮箱格式不正确」；密码不足 6 位会提示「密码格式不正确，至少需要6位」。

#### 3.2 编辑管理员

1. 在操作列点击 **编辑** 图标。
2. 修改姓名、邮箱、手机号、学校/机构、头像（编辑时不提供密码修改）。
3. 点击 **更新管理员**。

#### 3.3 删除管理员

1. 在操作列点击 **删除** 图标。
2. 在弹出的确认框中点击 **确定**。

> 如该管理员存在关联数据，系统会提示无法删除。

#### 3.4 查看管理员详情

在操作列点击 **查看** 图标，右侧抽屉展示：头像、用户ID、姓名、邮箱、手机号、学校/机构。

#### 3.5 批量导入管理员

1. 点击 **下载模板**，下载用户导入 Excel 模板。
2. 按模板填写管理员数据（含角色列，需为「管理员」）。
3. 点击 **导入管理员**，上传 Excel 文件（`.xlsx` 或 `.xls`）。
4. 系统解析并预览数据（逐行校验：工号/用户ID、姓名、密码位数、角色等）。
5. 确认无误后点击 **开始导入**。

### 第十二章 常见问题

#### Q1：为什么左侧导航没有「租户管理」「API Key 配置」？

这两个菜单仅超级管理员可见，普通管理员不可见。如需使用请联系超级管理员。

#### Q2：教师 / 学生忘记密码怎么办？

- 教师：在「教师管理」操作列点击 **修改密码** 重置。
- 学生：在「学生管理」操作列点击 **编辑**，填写「新密码（可选）」后保存。
- 管理员：编辑管理员时不提供密码修改，请通过其他途径联系技术支持处理。

#### Q3：删除学生提示「存在课程关联记录」怎么办？

该学生已关联课程，需先由教师在课程管理中移除该学生的选课关联，然后再删除学生。

#### Q4：为什么删除班级按钮不可用？

只有没有关联学生的班级才能删除。请先通过「取消关联」将班级内学生全部移出。

#### Q5：批量导入用户失败？

常见原因：
1. 未使用系统提供的模板。
2. 用户ID/工号重复。
3. 必填字段为空（用户ID、姓名、密码等）。
4. 密码不足 6 位。
导入前可先点击 **下载模板** 获取标准格式，导入时可在预览界面查看逐行校验结果。

#### Q6：为什么「系统状态」的数值一直在变？

该页面默认每 5 秒自动刷新一次，属于正常现象。可点击 **停止自动刷新** 暂停。

#### Q7：系统日志能查到哪些内容？

系统日志记录用户的学习行为（查看文件、观看视频、提交练习、提交作业、微专业学习等）。可通过操作类型下拉框和搜索框筛选，并可导出为 CSV。
