## 第一章 系统概述与登录

### 1.1 系统简介

智课云枢管理端是面向租户管理员（学校/学院管理员）的后台管理平台，用于管理组织机构、班级、教师、学生、管理员账号，配置权限和系统参数。

> 与超级管理员（superadmin）的区别：
> - **管理员**：管理单个租户（学校/学院）内的所有数据
> - **超级管理员**：跨租户管理，可创建/删除租户、配置全局参数

### 1.2 登录系统

1. 打开浏览器访问管理端地址
2. 输入用户名 `admin1`、密码 `bcs19800403`
3. 点击 **登录**

> 提示：登录页截图待补充。可参考 [`截图指南.md`](截图指南.md)。

### 1.3 界面布局

- **顶部栏**：租户切换、系统通知、用户菜单
- **左侧导航**：所有管理模块（数据看板、组织、班级、用户、权限、系统等）
- **主内容区**：当前页面内容

### 1.4 切换租户

> 仅超级管理员可见，普通管理员只属于一个租户。

1. 点击顶部 **租户切换** 下拉框
2. 选择目标租户
3. 系统切换到目标租户数据视图

### 1.5 退出登录

点击右上角用户头像 → **退出登录**

## 第三章 组织机构管理

### 3.1 组织列表

![组织列表](images/admin/a_02_organizations.png)

**功能描述**：管理租户下的组织机构（学校、学院、系部、教研室等层级）。

**页面说明**：
- 表格展示所有组织
- 字段：名称、schema 名、创建时间、操作
- 顶部操作：添加、导入、导出、搜索

**操作步骤**：

#### 添加组织

1. 点击 **添加组织**
2. 填写组织名称
3. 选择父组织（构成层级）
4. 填写组织描述
5. 点击 **保存**
6. 系统自动创建数据库 schema 并执行迁移

#### 编辑组织

1. 找到目标组织
2. 点击 **编辑**
3. 修改信息
4. 保存

#### 删除组织

1. 点击 **删除**
2. 二次确认
3. 系统删除组织及关联数据

#### 查看详情

1. 点击 **查看** 打开抽屉
2. 查看组织详细信息
3. 查看下属组织、用户

#### 导入组织

1. 点击 **导入**
2. 选择 Excel 文件
3. 系统解析预览
4. 确认导入

### 3.2 组织层级

组织支持树形层级，例如：

```
北京大学（租户）
├─ 计算机学院
│  ├─ 软件工程系
│  │  └─ 软件工程教研室
│  └─ 计算机系
└─ 数学学院
   └─ 应用数学系
```

## 第六章 学生管理

### 6.1 学生列表

![学生列表](images/admin/a_05_students.png)

**功能描述**：管理租户下所有学生账号。

**页面说明**：
- 表格字段：学号、姓名、性别、班级、邮箱、手机、状态、注册时间
- 顶部操作：添加、批量导入、导出、搜索
- 视图：表格视图 / 卡片视图

**操作步骤**：

#### 添加学生

1. 点击 **添加学生**
2. 填写：学号、姓名、密码、性别、邮箱、手机
3. 选择班级
4. 保存

#### 批量导入

1. 点击 **批量导入**
2. 下载 Excel 模板
3. 按模板填写：
   - 学号（必填、唯一）
   - 姓名（必填）
   - 班级（必填）
   - 邮箱、手机（可选）
4. 上传文件
5. 系统解析预览，显示错误行
6. 修正后确认导入

> 提示：导入前可下载示例模板，确保格式正确。

#### 编辑学生

1. 找到目标学生
2. 点击 **编辑**
3. 修改信息（学号不可改）
4. 保存

#### 重置密码

1. 点击 **重置密码**
2. 输入新密码或使用系统生成
3. 确认

#### 停用 / 启用

1. 点击 **停用** / **启用**
2. 确认操作
3. 状态更新

#### 删除学生

1. 点击 **删除**
2. 二次确认
3. 系统删除账号（软删除，保留历史数据）

### 6.2 批量导出

**操作步骤**：
1. 勾选目标学生（或全选）
2. 点击 **导出选中**
3. 选择导出字段
4. 系统生成 Excel 文件下载

### 6.3 学生搜索

- 支持按学号、姓名、班级、邮箱搜索
- 支持高级筛选：注册时间范围、状态

## 第九章 权限管理

### 9.1 权限模型

系统采用 RBAC 模型：
- **用户**：实际使用者
- **角色**：权限集合（如 admin、teacher、student）
- **权限点**：原子操作（如 "课程:创建"、"用户:删除"）

### 9.2 权限点管理

![权限点](images/admin/a_08_permissions.png)

**功能描述**：查看和管理系统所有权限点。

**页面说明**：
- 树形结构展示权限点
- 按模块分组：组织管理、用户管理、课程管理、权限管理等

**操作步骤**：
1. 进入权限管理
2. 浏览权限点树
3. 点击模块查看下属权限点
4. 权限点由系统预置，不建议手动增删

### 9.3 角色管理

**功能描述**：定义角色及其权限集合。

**操作步骤**：

#### 创建角色

1. 点击 **添加角色**
2. 填写：角色名称、描述
3. 选择权限点（多选）
4. 保存

#### 编辑角色权限

1. 在角色列表点击 **编辑权限**
2. 勾选/取消权限点
3. 保存

### 9.4 用户授权

**功能描述**：给用户分配额外角色或权限。

**操作步骤**：
1. 进入用户列表
2. 找到目标用户
3. 点击 **授权**
4. 选择角色或权限点
5. 保存

## 第十一章 API Key 配置

### 11.1 API Key 列表

![API Key](images/admin/a_10_api_keys.png)

**功能描述**：管理 AI 服务所需的 API Key。

**页面说明**：
- 表格字段：名称、提供商、模型、状态、创建时间、最后使用
- 操作：添加、编辑、删除、启停

**操作步骤**：

#### 添加 API Key

1. 点击 **添加 API Key**
2. 填写：
   - 名称（如 "通义千问生产环境"）
   - 提供商：OpenAI / Anthropic / 通义千问 / 百度千帆 / 智谱
   - API Key（敏感字段，加密存储）
   - Base URL（可选，自定义代理）
3. 选择默认模型
4. 设置配额：每日最大调用次数、QPS 限制
5. 保存

#### 测试连接

1. 在 API Key 列表点击 **测试**
2. 系统发起测试调用
3. 显示测试结果

#### 启停 / 删除

1. 点击 **启用** / **停用** 切换状态
2. 点击 **删除** 移除（需二次确认）

### 11.2 模型路由

**功能描述**：配置不同场景使用的模型。

**操作步骤**：
1. 进入模型路由
2. 为各场景选择模型：
   - 通用对话：GPT-4 / Claude
   - 试题生成：通义千问
   - 文件解析：自定义
3. 设置优先级、备用模型
4. 保存

### 11.3 使用监控

**功能描述**：查看 API Key 调用情况。

**操作步骤**：
1. 进入使用监控
2. 查看：调用次数、成功率、平均耗时、Token 用量
3. 按时间、模型筛选
4. 导出统计报告

## 第二十一章 常见问题

### Q1：忘记管理员密码怎么办？

- 找超级管理员重置
- 或通过数据库直接重置（需超管权限）

### Q2：批量导入学生失败？

常见原因：
1. Excel 格式不对：使用系统提供的模板
2. 学号重复：检查唯一性
3. 班级不存在：先创建班级
4. 必填字段为空：检查所有必填列

### Q3：如何快速给一批学生分配权限？

1. 创建用户组
2. 设置用户组权限
3. 批量添加学生到用户组
4. 学生自动获得对应权限

### Q4：API Key 配置后无法使用？

排查步骤：
1. 测试连接是否通过
2. 检查账户余额
3. 确认模型名称正确
4. 查看使用监控的错误日志

### Q5：操作日志能保留多久？

默认保留 90 天，可在系统配置中调整。

### Q6：如何给班级批量导入学生？

1. 进入班级管理
2. 选择目标班级
3. 点击 **批量导入学生**
4. 上传 Excel

### Q7：删除组织会有什么影响？

- 删除组织会删除下属所有数据（用户、班级、课程）
- **操作不可恢复**，请谨慎
- 建议先归档再删除

### Q8：管理员能跨租户操作吗？

普通管理员不能。跨租户操作需要超级管理员权限。
