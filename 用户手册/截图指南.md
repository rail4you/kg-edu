## 一、截图工具

### 推荐工具

| 工具 | 平台 | 特点 |
|------|------|------|
| **macOS 自带截图** | macOS | `Cmd + Shift + 4` 区域截图，`Cmd + Shift + 5` 录制 |
| **Snipping Tool** | Windows | 内置，支持延时截图 |
| **Greenshot** | 跨平台 | 免费，支持标注 |
| **ShareX** | 跨平台 | 免费开源，支持自动滚动截图 |
| **Chrome DevTools** | 跨平台 | `Ctrl+Shift+P` → `Capture full size screenshot` |

### 推荐设置

- **分辨率**：1440×900（桌面端）/ 375×812（移动端）
- **格式**：PNG
- **质量**：无损
- **去除**：浏览器调试栏、扩展程序图标、个人信息

## 四、截图后期处理

### 4.1 去除敏感信息

- 模糊化学生姓名、手机号、邮箱
- 遮挡真实数据
- 删除浏览器调试信息

### 4.2 标注重点

使用图片编辑工具（Preview、Photoshop 等）：

- 红色箭头标注关键按钮
- 红色框圈出关键区域
- 添加文字说明（如 "1. 此处点击"）

### 4.3 压缩图片

如图片过大（> 500KB），使用工具压缩：

```bash
# 使用 ImageMagick
convert input.png -quality 85 output.jpg

# 使用 pngquant
pngquant --quality=65-80 input.png
```

## 五、自动化截图（可选）

如需批量自动化截图，可使用 Playwright：

```javascript
// scripts/screenshot.js
const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage({ viewport: { width: 1440, height: 900 } });

  // 学生登录
  await page.goto('http://localhost:8081');
  await page.fill('input[name="username"]', 'chen');
  await page.fill('input[name="password"]', 'cjr123456');
  await page.click('button[type="submit"]');

  // 截取课程概览
  await page.goto('http://localhost:8081/student/course-overview');
  await page.screenshot({ path: '用户手册/images/student/s_01_dashboard.png' });

  await browser.close();
})();
```
