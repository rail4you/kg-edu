## 第一章 概述与登录

### 1.1 系统简介

课堂星是融合知识图谱与人工智能技术的智慧教学平台。学生端围绕「课程」组织学习内容，提供课程概述、课程视频、认知目标、教学资源、知识图谱、学习推荐、互动课堂、考试、实验、邮件问答等功能。

### 1.2 登录系统

1. 打开浏览器访问学校/机构分配的访问地址。
2. 在登录首页选择 **学生登录**。
3. 输入学校/机构分配的用户名和密码。
4. 若账号属于多个组织（租户），会弹出「选择组织」窗口，选择所在学校/机构后进入首页。

> 📷 学生登录表单：
>
> ![学生登录表单](images/student/s_00_login.png)

> 📷 选择组织：
>
> ![选择组织](images/student/s_00b_select_org.png)

### 1.3 首页布局

登录成功后进入系统首页，自上而下分为：

- **顶部导航**：首页、课程、微专业、教学资源库、示范教学包、数字教材、合作单位、关于我们。
- **精品课程轮播**：展示重点推荐课程（如「设计表现基础」），可左右切换。
- **快捷导航**：智慧课程、微专业、数字教材、教学资源库、示范教学包、关于我们。
- **学科分类**：按学科（理学、工学、艺术学、哲学等）分类展示课程入口。

> 📷 系统首页：
>
> ![系统首页](images/student/s_01_home.png)

### 1.4 退出登录

点击页面右上角用户菜单，选择 **退出登录** 返回登录首页。

## 第二章 课程浏览与选课

### 2.1 课程列表

> 📷 课程列表：
>
> ![课程列表](images/student/s_02_courses.png)

**入口**：首页顶部导航点击 **课程**（或快捷导航「智慧课程」）。

**功能描述**：浏览全部课程并进入学习。

**页面说明**：

- 课程卡片：展示课程名称、学校、授课教师、学习人数，以及「已选课 / 可选课」状态。
- 顶部提供 **全部学校** 及学校（租户）筛选按钮。

**操作步骤**：

1. 在首页点击顶部导航「课程」。
2. 浏览课程卡片，可通过学校筛选查看指定机构的课程。
3. 点击目标课程卡片进入课程首页。

### 2.2 课程首页（前端页）

> 📷 课程首页：
>
> ![课程首页](images/student/s_03_course_front.png)

**入口**：在课程列表点击课程卡片后进入。

**功能描述**：展示课程封面、简介与知识图谱，提供进入学习的入口。

**页面说明**：

- **课程简介**：课程核心内容介绍。
- **学习课程**：进入课程学习区。
- **查看知识图谱**：查看课程知识图谱。
- 图谱展示区：提供「层级面板」「放射图谱」视图切换，支持 **上一个图谱 / 下一个图谱**、**全屏** 查看。

**操作步骤**：

1. 在课程列表点击目标课程。
2. 点击 **学习课程** 进入课程学习区（见第三章）。
3. 或点击 **查看知识图谱** 先浏览课程图谱。

## 第三章 课程内容学习

进入课程学习区后，左侧导航按「内容 / 学习 / 互动 / 评测 / 工具」分组列出全部功能。本课程学习区左侧导航共 13 个页面：

| 分组 | 菜单 |
|------|------|
| 内容 | 课程概述、课程概览、图谱总览、专业知识图谱 |
| 学习 | 课程视频、认知目标、教学资源、学习推荐 |
| 互动 | 互动课堂 |
| 评测 | 考试系统、实验系统 |
| 工具 | 教师团队、邮件问答 |

### 3.1 课程概述

> 📷 课程概述：
>
> ![课程概述](images/student/s_04_overview.png)

**入口**：左侧导航「内容 → 课程概述」。

**功能描述**：课程总体信息介绍页，进入学习区的默认首页。

**页面说明**：页面按 Tab 组织课程信息：

- **基本信息**：课程名称、学分、学时、授课教师等。
- **教学目标**：课程教学目标。
- **课程结构**：课程章节/内容结构。
- **毕业要求**：课程对应的毕业要求指标。
- **章节目录**：章节列表。
- **教材信息**：推荐教材。

**操作步骤**：

1. 进入课程学习区后默认显示课程概述。
2. 点击上方 Tab 切换查看不同维度的课程信息。

### 3.2 课程概览

> 📷 课程概览：
>
> ![课程概览](images/student/s_intro.png)

**入口**：左侧导航「内容 → 课程概览」。

**功能描述**：以概览形式展示课程内容与学习任务。

**页面说明**：

- 视频/资源条目：展示「1 个视频」等学习内容卡片及发布状态。
- **立即参加**：直接进入对应学习活动。
- **预览附件**：查看附件内容。
- **展开更多**：展开更多内容条目。

**操作步骤**：

1. 点击左侧导航「课程概览」。
2. 浏览内容卡片，点击 **立即参加** 开始学习，或 **预览附件** 查看资料。

### 3.3 课程视频

> 📷 课程视频：
>
> ![课程视频](images/student/s_course-video.png)

**入口**：左侧导航「学习 → 课程视频」。

**功能描述**：集中查看课程教学视频。

**操作步骤**：

1. 点击左侧导航「课程视频」。
2. 在视频列表中选择视频进行播放学习。

### 3.4 认知目标

> 📷 认知目标：
>
> ![认知目标](images/student/s_knowledge-cognitive-goals.png)

**入口**：左侧导航「学习 → 认知目标」。

**功能描述**：查看课程知识点对应的认知目标体系。

**页面说明**：

- **认知目标层级**：知识点的认知目标层级结构。
- **认知目标分布**：各层级认知目标的分布情况。

**操作步骤**：

1. 点击左侧导航「认知目标」。
2. 查看认知目标层级与分布，了解各知识点要求达到的认知水平。

### 3.5 教学资源

> 📷 教学资源：
>
> ![教学资源](images/student/s_resource.png)

**入口**：左侧导航「学习 → 教学资源」。

**功能描述**：查看课程学习资源列表。

**页面说明**：

- **资源列表**：按类型展示课程资源（文件、链接等）。

**操作步骤**：

1. 点击左侧导航「教学资源」。
2. 在资源列表中点击资源进行预览或下载。

## 第十章 常见问题

### Q1：登录后提示选择组织怎么办？

说明该账号属于多个学校/机构，请选择你所在的学校（租户）后进入。

### Q2：课程列表里显示「可选课」和「已选课」有什么区别？

「可选课」表示你尚未加入该课程，点击进入课程首页后按提示选课/加入学习；「已选课」表示已加入，可直接进入学习。

### Q3：进入课程学习区后应该先看什么？

建议按左侧导航顺序学习：先看「课程概述」了解课程信息，再看「图谱总览」建立知识框架，然后按「课程视频 → 认知目标 → 教学资源 → 学习推荐」逐步学习。

### Q4：如何参加考试？

进入「考试系统」页面，在考试列表点击 **继续考试** 开始答题，完成后提交即可查看成绩。

### Q5：找不到某个学习内容？

部分内容需要教师发布后才对学生可见。如果页面显示为空，请先确认教师是否已发布相关内容，或切换其他课程查看。
