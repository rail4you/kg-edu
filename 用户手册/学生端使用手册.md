## 第一章 系统概述与登录

### 1.1 系统简介

智课云枢学生端是面向学生的在线学习平台，提供课程学习、知识图谱浏览、学习资源获取、在线考试、实验管理、学习推荐、AI 智能助手等功能，帮助学生高效完成学业。

**核心特性**：
- 📚 **课程学习**：在线学习课程章节，观看视频，完成作业
- 🧠 **知识图谱**：多维度可视化课程知识体系
- 📝 **考试实验**：在线考试、实验管理
- 🤖 **AI 助手**：智能问答、个性化学习辅导
- 🎓 **微专业**：主题式学习包，获得能力证书
- 📊 **学习数据**：学习进度、认知目标、推荐内容

> 提示：本系统推荐使用最新版 Chrome、Edge、Firefox 浏览器访问，分辨率 1280×720 以上体验最佳。

### 1.2 角色登录入口

访问系统后默认进入登录页，可选择角色入口：

| 角色 | 入口 | 说明 |
|------|------|------|
| 学生 | 点击 **学生登录** 卡片 | 学号 + 密码登录 |
| 教师 | 点击 **教师登录** 卡片 | 教职工号 + 密码登录 |
| 管理员 | 点击 **管理员登录** 卡片 | 管理员账号 + 密码登录 |

**学生登录步骤**：
1. 访问 `http://localhost:8081`
2. 在登录首页点击 **学生登录**
3. 输入用户名 `chen`、密码 `cjr123456`
4. 点击 **登录** 按钮
5. 如账号存在多个组织，选择目标组织

> 若忘记密码，请联系班级管理员或教师重置。

### 1.3 界面布局

学生端界面分为四大区域：

- **顶部栏**：系统 Logo、消息通知、搜索、用户菜单
- **左侧导航**：所有学习功能模块（可折叠）
- **面包屑**：显示当前位置
- **主内容区**：当前页面内容

### 1.4 退出登录

点击右上角用户头像 → **退出登录**

## 第二章 课程学习

### 2.1 首页 Dashboard

![首页](images/student/s_01_dashboard.png)

**功能描述**：登录后的默认首页，展示课程导航、推荐课程、学习入口。

**页面说明**：

2. 使用快捷导航快速进入目标模块

2. 使用顶部筛选器：按学科、按关键字
3. 浏览课程卡片
4. 点击课程查看详情
5. 已选课程直接进入学习，未选课程点击 **加入课程**

### 2.3 课程概览

![课程概览](images/student/s02-course-intro.png)

**操作步骤**：

2. 查看顶部统计信息了解课程规模
3. 切换 Tab 查看不同维度的信息
4. 在课程模块中点击章节可展开/折叠
5. 点击 **开始学习** 进入学习模式
6. 点击 **查看资源** 进入资源库

2. 阅读章节文字内容
3. 观看嵌入视频
4. 完成章节内的练习题
5. 点击 **标记完成** 记录学习进度
6. 点击 **下一章** 继续学习

**页面说明**：

## 第三章 知识图谱

### 3.1 图谱总览

![图谱总览](images/student/s04-graph-overview.png)

**功能描述**：以可视化方式展示课程知识图谱，支持多种视图模式查看知识点之间的关系。

**页面说明**：
- **顶部统计**：知识点数、关联数、习题数、文件数
- **视图切换**：树图、环图、层次结构图、问题图、思政图谱、能力图谱、分类图谱
- **搜索功能**：可搜索特定知识点
- **筛选器**：按章节、认知层级筛选
- **节点详情面板**：点击节点后右侧弹出

**操作步骤**：
1. 在左侧菜单点击 **图谱**
2. 默认进入图谱总览页面
3. 点击不同标签切换视图模式
4. 在搜索框输入知识点名称
5. 点击知识点节点查看详情
6. 通过鼠标拖拽、滚轮缩放浏览图谱
7. 点击 **导出图片** 保存图谱

---

### 3.2 树图视图

**入口**：图谱 → 树图

**功能描述**：以树形结构展示知识点层级关系。

**页面说明**：
- 根节点为课程
- 二级节点为主题
- 三级节点为知识单元
- 叶节点为知识点
- 节点显示：名称、知识点数量

**操作步骤**：
1. 切换到 **树图** 标签
2. 点击节点展开/折叠子节点
3. 点击叶节点查看知识点详情
4. 使用鼠标拖拽调整布局
5. 点击节点查看关联资源

**适用场景**：
- 快速了解课程结构
- 找到知识点所属主题和单元
- 自上而下系统学习

---

### 3.3 环图视图

**入口**：图谱 → 环图

**功能描述**：以环形布局展示知识点。

**页面说明**：
- 中心：课程或主题
- 环形：知识单元
- 外环：知识点
- 颜色编码：按主题或章节着色

**操作步骤**：
1. 切换到 **环图** 标签
2. 鼠标悬停查看节点信息
3. 点击节点查看详情
4. 使用滚轮缩放
5. 双击节点聚焦该节点

**适用场景**：
- 直观感受知识点分布
- 比较不同章节的知识点数量

## 第五章 考试与实验

### 5.1 考试列表

![考试](images/student/s07-exam-system.png)

**功能描述**：查看和参加课程考试。

**页面说明**：
- **考试统计**：可用考试数、已完成数
- **状态筛选**：全部状态、可用考试、已完成
- **视图切换**：卡片视图 / 列表视图
- **考试信息**：名称、类型、时长、总分、及格线、考试时间
- **考试类型**：单元测试、期中考试、期末考试、模拟考

**操作步骤**：
1. 左侧菜单点击 **考试系统**
2. 选择状态筛选：可用考试 / 已完成
3. 查看考试卡片或列表
4. 点击考试查看详情（时长、分数要求等）
5. 点击 **开始考试** 进入答题

---

### 5.2 考试答题

![考试答题](images/student/s_07_exam_taking.png)

**页面说明**：
- **顶部倒计时**：显示剩余时间
- **题目区**：当前题目（含题干、选项）
- **右侧答题卡**：显示所有题目作答状态
- **底部按钮**：上一题 / 下一题 / 标记 / 提交
- **自动保存**：每作答一题自动保存

**操作步骤**：
1. 阅读考试须知
2. 点击 **开始答题**
3. 仔细阅读题目
4. 选择答案：
   - 单选题：点击单选按钮
   - 多选题：勾选多个选项
   - 填空题：输入文字
   - 判断题：选择对/错
   - 简答题：输入文字
5. 点击 **标记** 标记存疑题目
6. 点击 **下一题** 继续作答

### Q1：忘记密码怎么办？

联系班级管理员或任课教师重置密码。

### Q2：考试时浏览器闪退怎么办？

考试系统会自动保存已答题目。重新登录后点击 **继续考试** 恢复（需在考试时间内）。

### Q3：视频无法播放？

- 检查网络连接
- 更换浏览器（推荐 Chrome）
- 联系管理员检查视频源

### Q4：如何查看学习进度？

进入 **学习推荐** 或 **认知目标** 页面查看。

### Q5：如何向教师提问？

- 使用 **邮件问答** 功能
- 进入 **讨论中心** 公开提问
- 教师邮箱联系（教师团队页面查看）

### Q6：如何加入微专业？

进入 **微专业** 列表，选择目标微专业 → 点击 **加入** → 等待管理员审核。

### Q7：作业可以补交吗？

视教师设置而定，超时未交需联系教师申请补交。

### Q8：AI 助手能帮我做什么？

- 解答学习疑问
- 辅导学习方法
- 推荐学习资源
- 生成练习题
- 总结学习内容
- 分析错题规律

### Q9：图谱上的节点颜色代表什么？

不同视图有不同的颜色编码：
- 树图：按主题着色
- 思政图谱：红色为思政融合点
- 能力图谱：按能力类型着色
- 悬停节点查看颜色说明

### Q10：如何切换账号？

点击右上角头像 → **退出登录** → 重新登录其他账号。

### Q11：手机端能用吗？

支持。使用手机浏览器访问系统地址，建议使用横屏或平板获得更好体验。

### Q12：数据会自动保存吗？

大部分数据会自动保存：
- 考试答题每题自动保存
- 作业草稿自动保存
- 表单内容自动保存

### Q13：如何导出我的学习数据？

个人中心 → 我的数据 → 导出（PDF/Excel）

### Q14：组任务如何分组？

教师或系统自动分组，也可在组任务详情查看自己的组员。

### Q15：能否离线使用？

当前版本不支持完全离线使用，但已学习的视频可在网络好时缓冲观看。
