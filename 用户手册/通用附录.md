# 智课云枢 - 通用附录

> 本附录为四本手册的通用部分，包含术语表、快捷键、FAQ 等。

---

## 一、术语表

| 术语 | 解释 |
|------|------|
| 租户（Tenant） | 数据隔离单位，通常对应一所学校或一个机构 |
| Schema | PostgreSQL 中的逻辑分组，用于实现多租户隔离 |
| 知识图谱 | 知识点及其关联关系的图形化表示 |
| 知识点 | 课程中的最小学习单元 |
| 主题 / 知识单元 / 知识点 | 三级层级，主题包含若干单元，单元包含若干知识点 |
| 认知目标 | 基于布鲁姆分类法的认知层级：记忆、理解、应用、分析、评价、创造 |
| 微专业（MM） | 由若干课程组成的主题式学习包 |
| AI 工作台 | 集成多种 AI 能力的统一入口 |
| 思政图谱 | 融入思政元素的知识点图谱 |
| 能力图谱 | 以能力目标为节点的图谱 |
| 角色 | 用户身份类别：student / teacher / admin / superadmin |
| 权限点 | 原子操作权限，如 "课程:创建" |
| RBAC | 基于角色的访问控制（Role-Based Access Control） |

## 四、常见问题（FAQ）

### 账号与登录

**Q1：忘记密码怎么办？**
- 学生/教师：联系班级管理员或任课教师重置
- 管理员：联系超级管理员重置
- 超级管理员：通过数据库直接重置（需 DBA 权限）

**Q2：账号被锁定怎么办？**
- 等待锁定时间结束（默认 30 分钟）
- 或联系管理员强制解锁

**Q3：能同时登录多个账号吗？**
- 同一浏览器同一时刻只能登录一个账号
- 可使用无痕模式登录另一个账号
- 或在不同浏览器登录不同账号

### 浏览器与性能

**Q4：页面加载慢？**
1. 检查网络连接
2. 清除浏览器缓存
3. 更换浏览器
4. 联系管理员检查服务状态

**Q5：视频无法播放？**
1. 检查网络
2. 确认浏览器支持视频格式
3. 关闭广告拦截插件
4. 联系管理员

**Q6：上传文件失败？**
1. 检查文件大小（默认 ≤100MB）
2. 检查文件格式
3. 检查网络
4. 刷新页面重试

### 数据与导出

**Q7：如何导出数据？**
- 列表页通常有 **导出** 按钮
- 支持 Excel、CSV 格式
- 大数据量请使用筛选后导出

**Q8：删除的数据能恢复吗？**
- 软删除的数据可在回收站恢复（30 天内）
- 硬删除的数据不可恢复（请提前备份）

### AI 功能

**Q9：AI 助手无响应？**
1. 检查网络
2. 检查 API Key 配置
3. 检查账户余额
4. 查看 AI 服务监控

**Q10：AI 生成内容不准确？**
- AI 生成内容仅供参考
- 请人工核对后使用
- 可通过反馈（点赞/点踩）帮助改进

### 微专业

**Q11：如何加入微专业？**
- 在微专业列表点击 **加入**
- 部分微专业需要审核
- 加入后按要求完成课程

**Q12：证书如何获取？**
- 完成微专业全部课程要求
- 通过考核
- 系统自动颁发证书

## 五、安全提示

1. **密码安全**
   - 定期更换密码
   - 不要使用简单密码
   - 不要将密码告知他人

2. **账号安全**
   - 不要在公共电脑保存密码
   - 离开电脑时退出登录
   - 启用双因素认证（如支持）

3. **数据安全**
   - 重要数据定期备份
   - 不要上传敏感信息到公共模块
   - 异常操作立即报告
