> 说明：本附录仅收录网站应用界面中已出现的术语与功能，未经验证的内容不予收录。

## 一、术语表

| 术语 | 解释 |
|------|------|
| 课堂星 | 融合知识图谱与人工智能技术的智慧教学平台（本系统名称） |
| 租户（Tenant） | 数据隔离单位，通常对应一所学校或一个机构；多组织账号登录时需选择租户 |
| 知识图谱 | 知识点及其关联关系的图形化表示 |
| 知识点 | 课程中的最小学习单元 |
| 认知目标 | 基于布鲁姆分类法的认知层级：记忆、理解、应用、分析、评价、创造 |
| 课程图谱 | 展示课程知识点及其关系的图谱 |
| 思政图谱 | 融入思政元素的知识点图谱 |
| 能力图谱 | 以能力目标为节点的图谱（含课程能力图谱、专业知识图谱） |
| 微专业（MM） | 面向产业人才需求、由若干课程组成的复合型人才培养方案 |
| AI 工作台 | 集成 AI 智能体助手、AI 生成试题、AI 文件、AI 命令中心的统一入口 |
| 虚拟教研室 | 以教研室为单位组织的教师协作空间 |
| 角色 | 用户身份类别：学生 / 教师 / 管理员 / 超级管理员 |
| 组织 / 学校 | 租户的通俗叫法，登录时通过「选择组织」窗口进入 |

## 四、常见问题（FAQ）

### 账号与登录

**Q1：忘记密码怎么办？**
- 请联系管理员/超级管理员在管理平台「教师管理」「学生管理」「管理员管理」页面重置密码。
- 管理员重置密码时，新密码需满足页面提示的位数要求（管理员≥6 位，教师≥8 位）。

**Q2：登录后提示选择组织怎么办？**
- 说明该账号属于多个学校/机构，选择你所在的学校（租户）后即可进入。

**Q3：能同时登录多个账号吗？**
- 同一浏览器同一时刻只能登录一个账号；可使用无痕模式或在不同浏览器登录不同账号。

### 页面与功能

**Q4：为什么部分页面没有数据？**
- 各页面通常需要先在上方选择课程/租户后才会展示数据；部分内容需教师发布后对学生可见。

**Q5：教师端部分按钮灰色不可点击？**
- 如「分组管理」「分组任务」等按钮需要先选择课程后才会启用。

**Q6：如何快速找到某个功能页面？**
- 教师端可使用左侧导航顶部搜索框（快捷键 `Ctrl/Cmd + K`）按名称搜索菜单，常用页面可加入「收藏夹」。

### 数据与导出

**Q7：如何导出数据？**
- 具体以各页面按钮为准，例如管理端「系统日志」页面提供 **导出 CSV** 按钮。

### AI 功能

**Q8：AI 助手无响应怎么办？**
- 检查网络连接；联系管理员确认系统 AI 服务与 API Key 配置是否正常。

**Q9：AI 生成内容准确吗？**
- AI 生成内容仅供参考，请人工核对后使用。

### 微专业

**Q10：如何加入微专业？**
- 在首页「微专业」列表中浏览微专业，进入详情页后按页面指引开始学习；微专业卡片上的状态标记（如「已通过」）表示审核状态。

## 五、安全提示

1. **密码安全**：定期更换密码，不要使用简单密码或将密码告知他人。
2. **账号安全**：不要在公共电脑保存密码，离开电脑时退出登录。
3. **数据安全**：重要数据及时备份，异常操作立即向管理员报告。
