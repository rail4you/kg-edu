# 用户手册格式转换说明

> 本文档介绍如何将 Markdown 格式的用户手册转换为 PDF、DOCX、HTML 等其他格式。

---

## 一、工具准备

### 1. Pandoc（必需）

```bash
# macOS
brew install pandoc

# Ubuntu/Debian
sudo apt install pandoc

# 验证安装
pandoc --version
```

### 2. PDF 引擎

推荐使用 **wkhtmltopdf** 或 **XeLaTeX**：

```bash
# macOS 安装 wkhtmltopdf
brew install --cask wkhtmltopdf

# macOS 安装 LaTeX（中文支持）
brew install --cask mactex-no-gui
```

### 3. 验证

```bash
pandoc --version  # 应显示 2.x 或更高
xelatex --version  # 如使用 LaTeX
wkhtmltopdf --version  # 如使用 wkhtmltopdf
```

---

## 二、转换为 PDF

### 方法 A：Pandoc + XeLaTeX（推荐）

```bash
pandoc 学生端使用手册.md \
  -o 学生端使用手册.pdf \
  --pdf-engine=xelatex \
  -V "mainfont=PingFang SC" \
  -V "geometry:margin=2cm" \
  -V "geometry:a4paper" \
  --toc \
  --toc-depth=2 \
  --number-sections
```

### 方法 B：Pandoc + wkhtmltopdf（中文支持更好）

```bash
pandoc 学生端使用手册.md \
  -o student.html \
  --self-contained \
  --metadata title="学生端使用手册" \
  --toc --toc-depth=2 \
  --css=pandoc.css

wkhtmltopdf \
  --enable-local-file-access \
  --encoding utf-8 \
  --margin-top 20mm --margin-bottom 20mm \
  --margin-left 20mm --margin-right 20mm \
  student.html 学生端使用手册.pdf
```

### 方法 C：使用本项目提供的构建脚本

```bash
cd 用户手册
./build.sh pdf           # 构建所有 PDF
./build.sh pdf student   # 仅构建学生端
```

## 三、转换为 DOCX

```bash
pandoc 学生端使用手册.md \
  -o 学生端使用手册.docx \
  --toc \
  --toc-depth=2 \
  --number-sections
```

或使用构建脚本：

```bash
./build.sh docx
```

### 自定义样式

如有 `template.docx` 模板文件：

```bash
pandoc 学生端使用手册.md \
  -o 学生端使用手册.docx \
  --reference-doc=template.docx \
  --toc --toc-depth=2
```

---

## 四、转换为 HTML

```bash
pandoc 学生端使用手册.md \
  -o 学生端使用手册.html \
  --self-contained \
  --toc --toc-depth=2 \
  --metadata title="学生端使用手册"
```

`--self-contained` 将图片等资源内嵌到单一 HTML 文件中。

## 五、批量转换

```bash
# 进入用户手册目录
cd 用户手册

# 一键构建所有格式
./build.sh all

# 仅 PDF
./build.sh pdf

# 仅 DOCX
./build.sh docx

# 仅 HTML
./build.sh html
```

构建脚本会生成：

```

├── 学生端使用手册.docx
├── 学生端使用手册.html

├── 教师端使用手册.html

```

## 六、中文字体配置

不同操作系统的中文字体不同，需调整 Pandoc 命令中的字体配置：

### macOS

```bash
-V "mainfont=PingFang SC" \
-V "sansfont=PingFang SC" \
-V "monofont=Menlo"
```

### Windows

```bash
-V "mainfont=Microsoft YaHei" \
-V "sansfont=Microsoft YaHei" \
-V "monofont=Consolas"
```

### Linux

```bash
# 安装中文字体
sudo apt install fonts-noto-cjk fonts-noto-cjk-extra

# 使用 Noto Sans CJK
-V "mainfont=Noto Sans CJK SC" \
-V "sansfont=Noto Sans CJK SC" \
-V "monofont=Noto Sans Mono CJK SC"
```

## 七、图片路径处理

由于图片在 `images/` 子目录下，Pandoc 会自动查找：

```
images/student/s_01_dashboard.png
```

确保转换时在 `用户手册/` 目录下执行：

```bash
cd 用户手册
pandoc 学生端使用手册.md -o out.pdf
```

如在其他目录执行，需指定 `--resource-path`：

```bash
pandoc 学生端使用手册.md \
  -o out.pdf \
  --resource-path=用户手册 \
  --resource-path=用户手册/images
```

## 八、常见问题

### Q1：PDF 中中文显示为方块？

解决：安装中文字体，并在 `-V "mainfont=..."` 中指定。

### Q2：图片不显示？

- 确认图片路径正确
- 使用 `--self-contained` 内嵌资源
- 或使用相对路径 `./images/...`

### Q3：目录样式不对？

调整 `--toc-depth` 参数（1-3）。

### Q4：DOCX 表格样式丢失？

使用 `--reference-doc` 指定模板 docx。

### Q5：超大文档转换慢？

- 拆分文档
- 减少图片大小
- 使用 `--no-highlight` 关闭代码高亮

## 九、CI/CD 集成（可选）

可在 GitHub Actions 中自动化构建：

```yaml
# .github/workflows/build-manual.yml
name: Build User Manual
on:
  push:
    paths:
      - '用户手册/**'

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y pandoc texlive-xetex fonts-noto-cjk
      - name: Build PDFs
        run: |
          cd 用户手册
          for f in 学生端使用手册 教师端使用手册 管理端使用手册 超级管理员使用手册; do
            pandoc "${f}.md" \
              -o "${f}.pdf" \
              --pdf-engine=xelatex \
              -V "mainfont=Noto Sans CJK SC" \
              --toc --toc-depth=2
          done
      - name: Upload artifacts
        uses: actions/upload-artifact@v3
        with:
          name: user-manuals
          path: 用户手册/*.pdf
```
