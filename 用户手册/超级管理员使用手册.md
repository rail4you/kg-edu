## 第一章 概述与登录

### 1.1 系统简介

课堂星是融合知识图谱与人工智能技术的智慧教学平台。超级管理员使用手册面向系统最高权限账号，介绍「管理平台」中各页面的功能。

管理平台入口为 `/admin/dashboard`（登录后自动进入）。

### 1.2 超级管理员与普通管理员的区别

超级管理员与管理员使用同一套管理平台，超级管理员在左侧导航中**多出两个专属菜单**：

| 菜单 | 超级管理员 | 管理员 |
|------|:---:|:---:|
| 管理控制台 | ✅ | ✅ |
| 租户管理 | ✅ | ❌ |
| API Key 配置 | ✅ | ❌ |
| 管理员管理 | ✅ | ✅ |
| 教师管理 | ✅ | ✅ |
| 学生管理 | ✅ | ✅ |
| 班级管理 | ✅ | ✅ |
| 小组管理 | ✅ | ✅ |
| 权限管理 | ✅ | ✅ |
| 系统状态 | ✅ | ✅ |
| 系统日志 | ✅ | ✅ |

> 超级管理员在「管理员管理」页面还可以通过租户下拉框选择要管理的租户。

### 1.3 登录系统

1. 打开浏览器访问学校/机构分配的访问地址。
2. 在登录首页选择 **管理员登录**。
3. 输入学校/机构分配的用户名和密码。
4. 如果账号属于多个组织，系统会弹出「选择组织」窗口，选择要登录的组织后继续。
5. 登录成功后自动进入 **管理控制台**。

> 📷 登录首页（角色选择）：
>
> ![登录首页-角色选择](images/superadmin/sa_00_login.png)

选择「管理员登录」后进入登录表单：

> 📷 管理员登录表单：
>
> ![管理员登录表单](images/superadmin/sa_01_login_form.png)

> 若账号属于多个组织，会弹出「选择组织」窗口：
>
> ![选择组织](images/superadmin/sa_01b_select_org.png)

### 1.4 界面布局

管理平台页面自上而下、自左而右分为四个区域：

- **顶部栏**：左侧为平台标识与「智慧教学系统 · 管理平台」标题（点击可返回管理控制台）；右侧为通知铃铛和用户头像菜单。
- **左侧导航**：列出当前角色可见的所有功能模块（超级管理员含「租户管理」「API Key 配置」）。
- **主内容区**：当前页面内容。
- **页脚**：版权信息。

> 管理平台整体布局见 [第二章 管理控制台](#第二章-管理控制台工作台) 截图。

### 1.5 退出登录与修改密码

1. 点击顶部栏右侧的用户头像。
2. 在弹出的抽屉面板中：
   - 点击 **修改密码**，依次输入当前密码、新密码（至少 6 位）、确认新密码，点击 **确认修改**。
   - 点击 **退出登录** 返回登录首页。

## 第二章 管理控制台（工作台）

> 📷 管理控制台页面：
>
> ![管理控制台](images/superadmin/sa_02_dashboard.png)

**入口**：登录后自动进入，或点击顶部栏品牌标识 / 左侧导航「管理控制台」。

**页面说明**：

- **功能模块**：以卡片形式列出当前角色可用的全部模块，点击卡片直接进入对应页面。超级管理员可见的模块包括：租户管理、API Key 配置、管理员管理、教师管理、学生管理、班级管理、小组管理、权限管理、系统状态、系统日志。

**操作步骤**：

1. 登录后查看顶部统计卡片，了解当前组织的用户与班级规模。
2. 点击任意功能模块卡片，进入对应管理页面。

## 第三章 租户管理

> 📷 租户管理页面：
>
> ![租户管理](images/superadmin/sa_03_tenants.png)

**入口**：左侧导航 → **租户管理**（仅超级管理员可见）。

**功能描述**：管理系统中的所有租户（组织），支持创建、编辑、删除、导入导出租户，并查看每个租户的数据规模。

> 权限说明：普通管理员访问此页面会显示「权限不足」提示，仅超级管理员可以管理租户。

### 3.1 租户列表

**页面说明**：

- 表格字段：**租户名称**、**Schema 标识**、**操作**。
- 页面左上角显示当前租户总数；右上角提供搜索框，可按租户名称或 Schema 标识搜索。

### 3.2 创建租户

**操作步骤**：

1. 点击右上角 **创建租户**。
2. 在弹出的窗口中输入 **租户名称**（必填）。
3. 点击 **创建**，系统自动创建该租户对应的数据库 schema 并完成初始化。

> 创建成功后，新租户会出现在租户列表中，可在「管理员管理」页面选择该租户为其添加管理员等账号。

### 3.3 编辑租户

1. 在租户列表的操作列点击 **编辑** 图标。
2. 修改 **租户名称**。
3. 点击 **保存**。

### 3.4 删除租户

1. 在租户列表的操作列点击 **删除** 图标。
2. 在弹出的确认框中点击 **确定删除**（弹窗会再次提示「删除租户及其所有数据，此操作不可撤销」）。

> ⚠️ 警告：删除租户会删除该租户下的全部数据（用户、课程、知识点等），**不可恢复**。删除前建议先导出备份。

### 3.5 导出租户

1. 在租户列表的操作列点击 **导出** 图标。
2. 系统生成该租户的数据导出文件（`.sql`）并自动下载。

> 导出的文件可用于该租户的数据备份，或通过「导入租户」在其他环境恢复。

### 3.6 导入租户

**功能描述**：通过上传导出文件（`.sql`），以新租户名称恢复完整数据（用户、课程、知识点等）。

**操作步骤**：

1. 点击右上角 **导入租户**。
2. 输入 **新租户名称**（必填）。
3. 选择之前导出的 `.sql` 文件。
4. 点击 **开始导入**，等待导入完成。

### 3.7 查看租户详情

1. 在租户列表的操作列点击 **查看** 图标，右侧弹出租户详情抽屉。
2. 详情内容包含：
   - **基本信息**：租户名称、Schema 标识。
   - **业务统计**：用户、课程、资源、习题、文件的数量。
   - **数据库统计**：业务表数量、总数据行数，以及各业务表的数据量明细（PostgreSQL 统计估算）。

## 第四章 API Key 配置

> 📷 API Key 配置页面：
>
> ![API Key 配置](images/superadmin/sa_04_api_keys.png)

**入口**：左侧导航 → **API Key 配置**（仅超级管理员可见）。

**功能描述**：配置系统 AI 服务（通义千问 Qwen / DashScope）所使用的 API Key。

> 权限说明：普通管理员访问此页面会显示「权限不足」提示。

**页面说明**：

- **API Base URL**：固定值 `https://dashscope.aliyuncs.com/compatible-mode/v1`，不可修改，可点击复制按钮复制。
- **模型**：`qwen-plus`（默认）/ `qwen-max`（高能力）。
- **当前 API Key**：以脱敏形式展示（仅显示首尾 4 位），可通过 **显示/隐藏** 按钮查看明文，通过 **复制** 按钮复制。
- **更换 API Key**：输入新的 DashScope API Key（`sk-...`）后点击 **保存并应用**，立即生效，无需重启服务；点击 **重置** 可清空输入框。

**说明提示**：

- API Key 保存后立即生效；系统优先使用数据库中保存的 Key，数据库无配置时回退到环境变量。
- 获取 API Key：阿里云百炼控制台（页面内提供入口链接）。

## 第五章 管理员管理

> 📷 管理员管理页面：
>
> ![管理员管理](images/superadmin/sa_05_admins.png)

**入口**：左侧导航 → **管理员管理**。

**功能描述**：管理各租户下的管理员账号（`admin` 角色），支持添加、编辑、删除、查看详情与批量导入。

### 5.1 选择要管理的租户

- 页面顶部信息栏显示当前管理范围。
- 超级管理员需要先通过租户下拉框 **选择租户**；未选择时信息栏提示「请选择要管理的租户」，列表为空。
- 信息栏右侧显示当前范围的管理员数量。

### 5.2 管理员列表

**页面说明**：

- 表格字段：**用户ID**、**姓名**（带头像）、**邮箱**、**手机号**、**学校/机构**。
- 支持按用户ID、姓名、邮箱、学校/机构关键词搜索。

### 5.3 添加管理员

**操作步骤**：

1. 点击右上角 **添加管理员**。
2. 在弹出的表单中填写：
   - **用户头像**：可选，点击上传图片。
   - **用户ID**（必填）：登录账号，需唯一。
   - **姓名**（必填）。
   - **邮箱**（可选，格式需正确）。
   - **手机号**（可选）。
   - **学校/机构**（可选）。
   - **密码**（必填，至少 6 位）与 **确认密码**。
3. 点击 **创建管理员**。

> 常见提示：用户ID 重复会提示「用户ID已存在」；邮箱格式错误会提示「邮箱格式不正确」；密码不足 6 位会提示「密码格式不正确，至少需要6位」。

### 5.4 编辑管理员

1. 在操作列点击 **编辑** 图标。
2. 修改姓名、邮箱、手机号、学校/机构、头像（编辑时不提供密码修改）。
3. 点击 **更新管理员**。

### 5.5 删除管理员

1. 在操作列点击 **删除** 图标。
2. 在弹出的确认框中点击 **确定**。

> 如该管理员存在关联数据，系统会提示无法删除。

### 5.6 查看管理员详情

1. 在操作列点击 **查看** 图标。
2. 右侧抽屉展示：头像、用户ID、姓名、邮箱、手机号、学校/机构。

### 5.7 批量导入管理员

1. 点击 **下载模板**，下载用户导入 Excel 模板。
2. 按模板填写管理员数据（含角色列，需为「管理员」）。
3. 点击 **导入管理员**，上传 Excel 文件（`.xlsx` 或 `.xls`）。
4. 系统解析并预览数据（逐行校验：工号/用户ID、姓名、密码位数、角色等）。
5. 确认无误后点击 **开始导入**。

## 第六章 教师管理

> 📷 教师管理页面：
>
> ![教师管理](images/superadmin/sa_06_teachers.png)

**入口**：左侧导航 → **教师管理**。

**功能描述**：管理当前组织的教师账号，支持添加、编辑、删除、重置密码、查看详情与批量导入。

**页面说明**：

- 顶部提示条显示「当前管理组织」。
- 表格字段：**用户ID**、**工号**、**姓名**（带头像）、**邮箱**、**手机号**、**学校/机构**、**职称**（助教 / 讲师 / 副教授 / 教授，以彩色标签展示）。
- 支持按用户ID、工号、姓名、邮箱、学校/机构关键词搜索。

### 6.1 添加教师

**操作步骤**：

1. 点击右上角 **添加教师**。
2. 填写表单：
   - **用户头像**（可选，上传图片）。
   - **用户ID**（必填，需唯一）。
   - **姓名**（必填）。
   - **工号**（可选）。
   - **邮箱**（可选）、**手机号**（可选）、**学校/机构**（可选）。
   - **密码**（必填，至少 6 位）与 **确认密码**。
   - **职称**（必选）：助教、讲师、副教授、教授。
   - **个人简介**（可选）。
3. 点击 **创建教师**。

### 6.2 修改教师密码

1. 在操作列点击 **修改密码** 图标。
2. 输入 **新密码**（至少 8 位）与 **确认密码**。
3. 点击 **确认修改**。

### 6.3 编辑 / 删除教师

- **编辑**：操作列点击 **编辑** 图标，修改信息后点击 **更新教师**。
- **删除**：操作列点击 **删除** 图标并确认；如教师存在关联记录，系统会提示无法删除。

### 6.4 查看教师详情

操作列点击 **查看** 图标，抽屉中展示：头像、用户ID、工号、姓名、邮箱、手机号、学校/机构、职称、个人简介。

### 6.5 批量导入教师

操作方式与「管理员管理 → 批量导入」相同（模板角色列填写「教师」）。

## 第七章 学生管理

> 📷 学生管理页面：
>
> ![学生管理](images/superadmin/sa_07_students.png)

**入口**：左侧导航 → **学生管理**。

**功能描述**：管理当前组织的学生账号，支持添加、编辑（含重置密码）、删除与批量导入。

**页面说明**：

- 顶部提示条显示「当前管理组织」。
- 表格字段：**学生ID**、**姓名**、**邮箱**、**学院**、**专业**、**关联班级**（以标签展示，未关联显示「未关联」）。
- 支持按学生ID、姓名、邮箱、学院、专业关键词搜索。

### 7.1 添加学生

**操作步骤**：

1. 点击右上角 **添加学生**。
2. 填写表单：
   - **学生ID**（必填，需唯一）。
   - **姓名**（必填）。
   - **密码**（必填，至少 6 位）与 **确认密码**。
   - **邮箱**（可选）、**手机号**（可选）。
   - **学院**（可选）、**专业**（可选）。
   - **关联班级**（可选）：从班级下拉框选择。
3. 点击 **创建学生**。

### 7.2 编辑学生（含重置密码）

1. 在操作列点击 **编辑** 图标。
2. 修改学生信息；如需重置密码，填写 **新密码（可选）** 与 **确认新密码**。
3. 点击 **更新学生**。

### 7.3 删除学生

1. 在操作列点击 **删除** 图标并确认。
2. 如学生存在课程关联记录，系统会提示「请先移除学生的课程关联后再删除」。

### 7.4 批量导入学生

操作方式与「管理员管理 → 批量导入」相同（模板角色列填写「学生」）。

## 第八章 班级管理

> 📷 班级管理页面：
>
> ![班级管理](images/superadmin/sa_08_classes.png)

**入口**：左侧导航 → **班级管理**。

**功能描述**：管理当前组织的班级，支持创建、编辑、删除班级，以及将学生关联 / 取消关联到班级。

**页面说明**：

- 表格字段：**班级名称**、**专业**、**学生人数**（以标签展示）。
- 支持按班级名称、学院、专业关键词搜索。

### 8.1 创建 / 编辑班级

**操作步骤**：

1. 点击右上角 **添加班级**（或操作列 **编辑** 图标）。
2. 填写：**班级名称**（必填）、**学院**（可选）、**专业**（可选）。
3. 点击 **创建** / **更新**。

### 8.2 关联学生

1. 在操作列点击 **关联学生** 图标。
2. 在弹出的窗口中选择班级（已自动选定当前班级），勾选要加入该班级的学生（支持搜索）。
3. 点击 **确认关联**。

### 8.3 取消关联

1. 在操作列点击 **取消关联** 图标（仅当班级内有学生时可用）。
2. 在弹出的窗口中选择要移出的学生。
3. 点击 **确认取消关联**。

### 8.4 删除班级

- 操作列点击 **删除** 图标并确认。
- 仅当班级内没有关联学生时才能删除；有学生的班级需先取消全部学生关联。

## 第九章 小组管理

> 📷 小组管理页面：
>
> ![小组管理](images/superadmin/sa_09_groups.png)

**入口**：左侧导航 → **小组管理**。

**功能描述**：管理当前组织的学生小组，支持创建、编辑、删除小组，以及为小组添加 / 移除成员。

**页面说明**：

- 表格字段：**小组名称**、**描述**、**人数上限**、**成员数**。
- 支持按小组名称、描述关键词搜索。

### 9.1 创建 / 编辑小组

**操作步骤**：

1. 点击右上角 **添加小组**（或操作列 **编辑** 图标）。
2. 填写：**小组名称**（必填，如「第一小组」）、**描述**（可选）、**人数上限**（可选，不填则无上限）。
3. 点击 **创建** / **更新**。

### 9.2 添加成员

1. 在操作列点击 **添加成员** 图标。
2. 在弹出的窗口中选择学生（支持搜索、多选）。

## 第十四章 常见问题

### Q1：为什么我在「租户管理」「API Key 配置」看不到内容？

这两个页面仅超级管理员可见。请确认登录账号为超级管理员角色（账号由系统管理员分配），普通管理员访问会提示「权限不足」。

### Q2：创建租户后如何为它添加管理员？

创建租户后，进入「管理员管理」页面，在顶部租户下拉框中选择该租户，再点击 **添加管理员** 创建账号。

### Q3：如何备份 / 恢复某个租户的数据？

- 备份：在「租户管理」中对该租户点击 **导出**，下载 `.sql` 文件。
- 恢复：在「租户管理」中点击 **导入租户**，填写新租户名称并上传导出的文件。

### Q4：删除了租户还能恢复吗？

不能。删除租户会删除其全部数据且不可撤销，删除前请先导出备份。

### Q5：教师 / 学生忘记密码怎么办？

- 教师：在「教师管理」操作列点击 **修改密码** 重置。
- 学生：在「学生管理」操作列点击 **编辑**，填写「新密码（可选）」后保存。
- 管理员：编辑管理员时不提供密码修改，请通过其他途径联系技术支持处理。

### Q6：修改 API Key 后需要重启服务吗？

不需要。点击 **保存并应用** 后立即生效；系统优先使用数据库中的 Key，未配置时回退到环境变量。

### Q7：为什么「教师管理 / 学生管理」等页面只显示一部分数据？

这些页面基于当前登录组织的数据。超级管理员如需管理其他租户，请在「管理员管理」页面通过租户下拉框切换（该页面支持跨租户选择）。
