## 2. 本次新演示任务

### 2.1 需求 10：AI 助教插件

**演示要点**：
1. 自定义大模型兜底回复开关、联网搜索开关。
2. 单智能体应用池、自建插件、MCP 服务维护。
3. 插件至少支持：移动端通知推送、富文本 Word 导出、生成图表、地图工具、发送邮件、Excel 导出、PPT 生成、获取任务流外部历史消息、网页解析、知识点双率统计、Word 导出、共享课程搜索（Word 导出出现两次，按一项计 + 双率统计，实际落地 11 种）。
4. MCP 服务至少支持：网页解析、联网搜索、图片 OCR、天气预报、办公写作、教育教学、工作汇报、文案助手（8 种）。

**技术方案（全部复用现成能力，不造新轮子）**：
- 新资源（归入现有 `KgEdu.AI` 域，无需改 `ash_domains`）：
  - `AssistantSetting`（租户级单例行）：`fallback_enabled`、`web_search_enabled`。
  - `AssistantTool`（应用池/自建插件/MCP 注册表）：`name`、`kind`（builtin/plugin/mcp）、`plugin`（插件类型名）、`config`（map： endpoint/key 等）、`enabled`。
- `PluginRunner` 模块：按 `plugin` 名分发到已有服务——邮件（Swoosh `EmailSender`）、Word/DOCX（`DocumentTools`）、PPT（`GeneratePowerPoint` 链路）、Excel（`Elixlsx`，参考测试 helper）、图表（回 ECharts option JSON）、地图（回 OSM embed URL）、网页解析（`Req` 抓取 + 去标签截断）、历史消息（`Conversation` read）、知识点双率（复用掌握度 `LearningAnalyzer`：掌握率/正确率）、共享课程搜索（`Course` read 按名过滤）、通知推送（写 `ActivityLog` + 可选邮件兜底，演示注明对接厂商推送预留）。
- MCP 目录接口 `GET /api/assistant/mcp-tools`：运行时枚举全部 `ash_domains` 下 `AshAi.Info.tools`（P0 已验证 8 个，P1–P4 新增的 read tools 自动出现），真实演示"我们的 MCP 服务"；外部 MCP 服务走 `AssistantTool(kind=mcp)` CRUD 存配置。
- 联网搜索：免 Key 方案——OpenAlex/Semantic Scholar（学术）+ DuckDuckGo Instant Answer（通用）HTTP 直调，失败降级提示；开关存 `AssistantSetting`，chat 链路读取开关决定是否注入搜索结果（P1 演示先做到"开关可配 + 插件run可用"，chat 注入作为可选增强）。
- 前端 `assistant-plugins.tsx`（教师端）：两开关 + 应用池表格（启用/禁用/配置）+ 插件试运行控制台（选插件→填参→看结果，图表类即时渲染 ECharts）+ MCP 服务页（本服务工具目录 + 外部 MCP 注册）。

### 2.2 需求 12：AI 追踪

**演示要点**：
1. 输入研究兴趣 → 自动生成/推荐相关方向 → 点击"追踪"持续跟进最新文章。
2. 学者追踪：基于成果构建"学者数字分身"，智能对话，把握方向与观点。
3. 期刊追踪：AI 提炼文章要点、对比观点、识别技术趋势。

**技术方案（免 Key 学术 API，演示稳定）**：
- 数据源：**OpenAlex**（`https://api.openalex.org`，免 Key，覆盖论文/作者/期刊/主题）为主；Semantic Scholar 作补充（引用数）。
- 新资源 `ResearchFollow`（归入 `KgEdu.AI` 域）：`kind`（interest/scholar/venue）、`ref_id`、`label`、`extra`（map：缓存快照）。
- `ScholarService` 模块：`search_works(query)`（兴趣→论文列表→顺带抽取 top 主题做"推荐方向"）、`search_authors(name)`、`author_works(openalex_id)`（分身语料：方向、代表作、被引）、`venue_digest(venue)`（近 N 篇→ LLM 提炼要点/观点对比/趋势，无 Key 时降级为抽取式摘要：标题+摘要拼接+高频词）。
- 学者分身对话：取其 Top 作品拼 system prompt，经现有 `/agent/api/chat`（复用 P3 的 `chatOnce`）\((分身页直接复用该 helper\)。
- 前端 `research-track.tsx`：三 Tab（兴趣追踪：搜索→推荐方向 chips→追踪按钮→列表；学者追踪：搜学者→画像卡→分身对话；期刊追踪：选刊→digest 卡片→趋势条）。
