## 1. AI 语音合成（听力/口语）🔑

1. 教师端打开任意听力题编辑（或 TTS 接口页）。
2. 输入中文文本 → 选女声晓春 → 语速 1.0 → 合成试听。
3. 切换英文文本 + 多语言音色 → 合成试听；调语速 0.8/音量 → 对比效果。
4. 将音频挂到听力题/口语测评题下保存。
- 接口：`GET /api/tts/voices`（已验证 5 音色）、`POST /api/tts/synthesize`。
- 预期：返回 OSS 音频 URL，前端可直接播放。

## 2. 人脸识别与抓拍

教师端 → 人脸识别与抓拍演示页（`/teacher/dashboard/face-check`）：
1. 打开摄像头 → 依次点"进入课程/视频起始/播放中/暂停再播放/视频结束"抓拍（快照存 OSS + 记录落库）。
2. 右侧打开"定时抓拍（10 分钟）+ 随机抓拍"开关。
3. 点"模拟识别失败"：先切"记录并继续学习"→ 警告但可继续；再切"不允许学习" → 红色遮罩阻止 + "重新验证"按钮。
4. 下方抓拍记录表验证每一条（含快照链接）。

## 3. AI 实践（6 场景）🔑

教师端 → AI 实践页（`/teacher/dashboard/ai-practice`）：
1. 切 Tab：情景对话 → 输入"在餐厅点餐"→ 多轮对话（含每轮表达建议）。
2. 思辨擂台 → 输入论点 → 看反方反驳 + 逻辑点评。
3. 代码编辑 → 粘贴一段代码 → 看评审 + 优化代码块。
4. 点"AI 实时评估并生成报告"→ 展示分数 Tag + 评估报告卡（已落库，可查记录）。

## 4. AI 组卷

教师端 → 考试管理 → 进入"【演示】期中试卷"组卷页：
1. 点"智能组卷"→ 粘贴大纲（`单选题 5题 每题2分 难度1,2` 换行写 2–3 类）→"按大纲填充配置"→ 配置自动填好。
2. "预览组卷结果"→ 每题点"换一题"🔑（AI 重出一题替换该行）→ 移除 1 题 →"确认添加"。🔑
3. 统计页 → 试卷分析区：题型统计（题量/分数/占比）、难易度统计（Tag 颜色）、题目明细表（按难易度筛选、按正确率排序，正确率列显示 100%/50%/30% 与作答次数）。

## 5. 试卷自定义导出

统计页点"打印试卷"（或直达 `/teacher/dashboard/exam-print/<examId>`）：
1. 版式切换 A4 → A3 → B4，看纸张宽度变化。
2. 密封线开/关、左/右切换；承诺书文本改一句；课程/学生信息开关。
3. 点"导出/打印"→ 浏览器打印预览（即模板配置效果验证）。

## 6. AI 章节视频解析 🔑（解析记录已预置，无 Key 也可走 UI）

教师端 → 课程视频 → 紫色 AI 图标 → 解析页：
1. 左侧播放器播放；右侧"摘要"Tab 读摘要。
2. "分段总结"→ 点某段"观看"→ 播放器自动定位。
3. "知识点打点"→ 点"定位播放"→ 跳到 2:10（机器学习）/5:10（神经网络）。
4. "思维导图"（Tree 结构）、"知识点词云"（Tag 云）。
5. 点"发起 AI 解析"→ 状态轮询 pending→processing→done（需 Key；演示可用预置 done 记录讲解）。

## 7. 移动端自定义表单

1. 教师端 → 自定义表单页：标题"会议室申请"+分类→ 添加单选/多选/下拉/图片/附件题目 → 设 1 个必填 → 保存。
2. 学生端（移动端尺寸演示：浏览器窄窗口）→ 我的表单 → 选表 → 必填项空着点提交 → 被拦截提示 → 填完提交。
3. 回教师端 → 该表"审批"→ 看到待审核记录。

## 8. 审批（AI 填表 + AI 公式）🔑

1. 学生填报页 → AI 填表卡输入"因感冒请假三天，从明天开始"→"按描述回填"→ 事由/天数自动填入；填图片 URL →"识别图片回填"。
2. 教师建表 → 加"计算字段"→ 描述"天数乘以每天200元"→"AI 生成公式"→ 表达式回填 + 解释 + 示例验算。
3. 学生提交 → 教师"审批"→ 批准/驳回 → 学生端状态同步。
