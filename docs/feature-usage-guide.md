## 功能一：分组任务

### 功能说明
教师可以在课堂互动中创建学生分组，布置分组任务，通过二维码分发给学学生参与，教师端可跟踪完成进度。

### 访问方式

| 页面 | 路由 | 角色 | 说明 |
|------|------|------|------|
| 分组管理 | `/teacher/dashboard/group-management` | 教师 | 创建小组、添加成员、随机分组 |
| 分组任务 | `/teacher/dashboard/group-task` | 教师 | 创建任务、发布、生成二维码、查看进度 |
| 扫码任务入口 | `/student/group-task/{tenantSchema}/{token}` | 学生 | 扫码进入、查看任务、提交内容 |

### 操作流程

1. **教师创建小组**
   - 进入「分组管理」页面 → 选择课程 → 点击「创建小组」→ 填写名称/描述 → 保存
   - 也可点击「随机分组」自动将课程学生分成 N 组

2. **教师布置任务**
   - 进入「分组任务」页面 → 选择课程 → 点击「创建任务」→ 填写标题/类型/描述/截止日期 → 保存

3. **发布任务并分发**
   - 在任务列表点击「发布」→ 自动生成二维码弹窗
   - 复制链接或截图二维码发给学生
   - 学生扫码进入任务页面 → 填写内容 → 点击「提交任务」

4. **跟踪进度**
   - 教师在任务列表可查看状态（草稿/进行中/已结束）
   - 可随时关闭已完成的任务

### 菜单位置
教师端左侧菜单 → 教学资源 → 「分组管理」「分组任务」

### 任务类型
- 提交任务（文本+文件上传）
- 讨论任务
- 投票调查
- 文件上传

## 功能二：学生学情画像

### 功能说明
整合学生多维度学习数据，构建动态数字画像，立体呈现学员知识掌握、学习行为与能力素养。

### 访问方式

| 页面 | 路由 | 角色 | 说明 |
|------|------|------|------|
| 学生学情画像 | `/teacher/dashboard/student-profile` | 教师 | 选择课程+学生，查看多维度画像 |

### 操作流程

1. 进入「学生学情画像」页面
2. 在顶部选择「课程」和「学生」
3. 页面自动加载以下内容：

### 画像内容

| 区域 | 图表类型 | 展示内容 |
|------|----------|----------|
| 总览卡片 | 统计卡片（4个） | 知识掌握度、学习活跃度、考试平均分、出勤率 |
| 知识掌握 | 雷达图 | 按主能力维度展示掌握度，与班级平均对比 |
| 学习行为 | 饼图 | 视频学习/资料阅读/练习答题/作业提交的占比 |
| 学习趋势 | 折线图 | 按周聚合的学习活动趋势 |
| 能力维度 | 柱状图 | 各子能力的得分与班级平均对比 |
| 薄弱知识点 | 表格 | 掌握度低于阈值的知识点列表 |

### 菜单位置
教师端左侧菜单 → 教学分析 → 「学生学情画像」

### 数据来源
- 知识点掌握度（StudentKnowledgeMastery）
- 活动日志（视频观看、文件访问、练习提交等）
- 考试成绩（StudentExam）
- 出勤记录（CheckInRecord）
- 能力维度（MainAbility + SubAbility）

## 功能三：专业分析

### 功能说明
独立模块，基于录入的专业信息，调用 AI 服务开展岗位分析、能力分析，构建专业能力素质图谱，AI 辅助人才培养设计。

### 访问方式

| 页面 | 路由 | 角色 | 说明 |
|------|------|------|------|
| 专业管理 | `/teacher/dashboard/major-list` | 教师 | 增删改查专业信息 |
| 专业详情 | `/teacher/dashboard/major-detail/{id}` | 教师 | 总览页，进入各子模块 |
| 岗位管理 | `/teacher/dashboard/major-jobs/{majorId}` | 教师 | 管理岗位、AI 分析 |
| 能力图谱 | `/teacher/dashboard/major-competency/{majorId}` | 教师 | 构建/编辑能力体系 |
| 课程体系 | `/teacher/dashboard/major-curriculum/{majorId}` | 教师 | AI 辅助设计课程体系 |
| 分析报告 | `/teacher/dashboard/major-report/{majorId}` | 教师 | AI 生成分析报告 |

### 操作流程

1. **创建专业**
   - 进入「专业管理」页面 → 点击「添加专业」→ 填写名称/代码/学院/学位类型/学制 → 保存

2. **进入专业详情**
   - 在专业列表点击专业名称 → 进入详情页，看到四个模块入口卡片：
     - 岗位管理与分析
     - 能力图谱构建
     - 课程体系设计
     - 分析报告

3. **岗位管理与分析**
   - 进入「岗位管理」→ 点击「添加岗位」→ 填写岗位名称/描述/要求/薪资 → 保存
   - 点击某岗位的「AI 分析」→ AI 自动分析该岗位的核心技能、发展前景、能力要求
   - 点击「查看」→ 查看岗位详情和 AI 分析结果

4. **能力图谱构建**
   - 进入「能力图谱」→ 手动添加能力节点（名称/类别/级别/权重）
   - 类别：专业能力、通用能力、实践能力
   - 支持树形层级结构

5. **课程体系设计**
   - 进入「课程体系设计」→ 点击「AI 生成课程体系」
   - AI 基于专业信息和能力数据自动生成课程体系方案
   - 可预览 JSON 格式的课程数据
   - 可发布方案

6. **分析报告**
   - 进入「分析报告」→ 点击「AI 生成报告」→ 选择类型：
     - 岗位分析
     - 能力图谱
     - 课程体系
     - 综合分析
   - AI 自动生成 Markdown 格式报告 → 可在线预览

### 菜单位置
教师端左侧菜单 → 「专业分析」→ 「专业管理」

## 技术说明

### 后端新增 Ash 域

| 域 | 资源数 | 说明 |
|----|--------|------|
| `KgEdu.GroupTask` | 5 | Group, GroupMember, Task, TaskGroup, TaskSubmission |
| `KgEdu.MajorAnalysis` | 5 | Major, JobPosition, MajorCompetency, CurriculumDesign, AnalysisReport |

### 后端新增服务模块

| 模块 | 说明 |
|------|------|
| `KgEdu.Knowledge.StudentProfile` | 学生画像聚合（6 个查询函数） |

### 新增数据库表（租户级）

groups, group_members, group_tasks, task_groups, task_submissions, majors, job_positions, major_competencies, curriculum_designs, analysis_reports

### 前端新增页面（10 个）

教师端：group-management, group-task, student-profile, major-list, major-detail, major-jobs, major-competency, major-curriculum, major-report
学生端：student/group-task（扫码入口）

### 前端依赖
- 所有页面使用 `ash_rpc.ts` 生成的类型安全函数
- 图表使用 ECharts（已在项目中使用）
- 二维码使用 Ant Design QRCode 组件
