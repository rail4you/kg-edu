# 首页改版方案 (学银风格)

## 参考网站
https://www.xueyinonline.com/xueyinonline-ans-vue/

## 改版目标
将现有首页从 Coursera 风格改为学银风格，保留核心功能但更新视觉设计。

## 1. 顶部导航 (Header)

### 当前实现
- Logo + "智慧教学系统" 标题
- 登录下拉菜单（学生/教师/管理员）
- 认证用户显示用户名

### 新实现
- 简洁 Tab 导航：首页 | 课程 | 登录 | 搜索
- Logo 居左
- 保持简洁，去掉多余的描述文字

## 2. Hero 区域

### 当前实现
- 蓝色渐变背景 (Coursera 风格)
- "开启学习之旅" 标题
- 搜索框 + 热门标签

### 新实现
- 使用学银风格配色和布局
- 可能需要生成新的背景图片效果
- 简化设计，保持清新风格

## 3. 课程卡片

### 当前实现
- 封面图 + 难度标签 + 已选课标签
- 标题 + 学校名 + 评分 + 人数
- 课时和分类信息

### 新实现
- 保持核心信息，简化视觉设计
- 调整配色和间距
- 移除 Coursera 风格元素

## 4. 底部Footer

### 当前实现
- 简单一行文字："智慧教学系统 © 2026 - 融合知识图谱与人工智能技术"

### 新实现
- 参考学银网站的 Footer 设计
- 可能包含更多链接和信息
- 更好的视觉层次

## 5. 筛选栏

### 当前实现
- 分类标签横向滚动
- 学校下拉筛选

### 新实现
- 简化设计
- 可能需要调整布局

## 技术实现

### 颜色方案
- 主色调：学银风格蓝色/青色系
- 背景色：浅色背景
- 强调色：用于按钮和标签

### 图片资源
- Hero 背景：可能需要使用 multimodal-toolkit 生成
- 保持现有课程封面图片

1. 更新 Header 导航
2. 简化 Hero 区域
3. 重新设计课程卡片样式
4. 更新 Footer 设计
5. 调整整体配色
