# Computer Science and Software Engineering (Programmer Track)

## I. Program Goals

### Mission
To cultivate industry-ready programmers who combine deep technical mastery with ethical judgment, collaborative fluency, and adaptive problem-solving across evolving digital landscapes.

### Graduate Profile
Upon graduation, students will:
- Design, implement, test, deploy, and maintain robust, secure, and sustainable software systems
- Apply algorithmic thinking, mathematical modeling, and data analysis to solve real-world problems
- Collaborate effectively in global, cross-functional teams using modern engineering practices
- Critically evaluate technologies, architectures, and methodologies through evidence-based reasoning
- Communicate technical concepts clearly in written, visual, and oral forms for diverse audiences
- Navigate professional responsibilities including data ethics, accessibility, environmental impact, and regulatory compliance
- Continuously learn and adapt to emerging tools, frameworks, and domain contexts

## IV. Core Course Descriptions

### Computational Thinking & Python Programming (CS101)
**Goal:** Equip students with foundational computational problem decomposition, abstraction, and implementation skills. Students will build a command-line productivity tool (e.g., smart note-taker, habit tracker, or code snippet manager) using Python, unit testing (pytest), and version control.

### Data Structures & Algorithms I (CS201)
**Goal:** Develop rigorous analysis of time/space complexity and mastery of core abstract data types. Students implement and benchmark search algorithms (linear, binary, hash-based) against real datasets, culminating in a lightweight search engine prototype supporting fuzzy matching and ranking.

### Software Engineering Principles (SE301)
**Goal:** Internalize professional engineering practice beyond coding. Using Scrum simulations, students manage a semester-long feature backlog for an open-source project, write RFC-style proposals, conduct risk assessments, and deliver release notes and post-mortems.

### Applied Machine Learning (AI350)
**Goal:** Demystify ML as a tool—not magic—by focusing on data curation, model selection rationale, evaluation rigor, and bias detection. Students build and audit a fairness-aware recommendation system using real-world datasets (e.g., MovieLens with demographic proxies).

### Capstone Project I & II (SE490/491)
**Goal:** Synthesize all competencies in an authentic, scaffolded, industry-aligned experience. Teams select a domain (e.g., climate tech dashboard, edtech accessibility plugin, healthtech patient portal), define success metrics with external stakeholders (faculty + industry mentors), iterate via bi-weekly demos, and deliver production-grade artifacts: deployed app, architecture decision records (ADRs), security report, sustainability impact summary, and public-facing documentation.

## V. Practice Component Breakdown

- **Collaborative Coding Labs (4 credits)**: Git history archaeology, PR etiquette drills, CI/CD pipeline authoring, containerization labs, observability instrumentation (logs/metrics/traces)
- **Prototyping Studio (2 credits)**: Weekly UX sprints, usability testing with real users, Figma-to-code handoff, accessibility audits
- **Industry Internship Prep (2 credits)**: Mock interviews (technical + behavioral), portfolio critique, contract negotiation role-play, platform-specific prep (LeetCode, HackerRank, Codility)
- **Capstone Project I & II (12 credits)**: 2-semester sequence with mandatory stakeholder engagement, iterative delivery, production deployment, and formal defense
- **Open-Source Contribution Sprint (2 credits)**: Guided contribution to vetted OSS projects (e.g., VS Code extensions, Pandoc filters, Python library docs)
- **Green Coding Lab (2 credits)**: Energy profiling (Scaphandre), carbon footprint estimation (CodeCarbon), low-power architecture design
- **Security & Ethics Practicum (2 credits)**: Threat modeling workshop, penetration testing lab (DVWA), privacy impact assessment (PIA) drafting
- **Technical Writing Intensive (2 credits)**: Docs-as-code bootcamp, API specification writing (OpenAPI), RFC authoring, README-first challenges
- **Total Practice Credits: 32 (structured labs) + 36 (capstone + internship prep + electives with practice focus) = 68 credits**
