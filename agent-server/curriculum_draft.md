# Curriculum Design Brief

## Program Name
Computer Science and Software Engineering (Programmer Track)

## Target Role
Entry-to-mid-level Programmer, Full-Stack Developer, AI-Enabled Application Developer

## Guiding Principles
- Project-driven learning from Semester 1 onward
- Practice weight ≥ 40% of total credits
- Every core course includes a semester-long capstone project or integrated micro-projects
- Industry-aligned toolchains: Git/GitHub, CI/CD, Docker, cloud platforms (AWS/Azure), modern IDEs, Jupyter, Figma, Postman
- Ethics, security, sustainability, and communication embedded in all technical courses
- Scaffolded progression: from algorithmic thinking → system design → enterprise integration → domain adaptation

## Capability Mapping Strategy
- Professional Core Competencies → Core coding & architecture courses
- Foundational Theory → Math, logic, discrete structures, OS, networks
- Technical Methods → DevOps, testing, debugging, profiling, documentation
- Industry Awareness → Guest lectures, case studies, open-source contribution, tech radar modules
- Critical Thinking & Logic → Problem decomposition labs, code review workshops, design critique sessions
- Cross-cultural Collaboration → Global team projects (with time-zone-aware workflows), IETF/RFC-style spec writing
- Digital Literacy → Toolchain fluency assessments, prompt engineering for AI pair programming
- Experimental Design → A/B testing labs, performance benchmarking, usability studies
- Full-Project Lifecycle → Integrated project sequence across Semesters 2–7
- Domain Adaptation → Electives + capstone domains (healthtech, edtech, climate tech, fintech)
- Mathematical Modeling → Stats + ML math + simulation labs
- Literature Synthesis → Research paper sprints, annotated bibliography assignments
- Algorithmics & Data Analysis → Paired with visualization and storytelling
- AI Application → Not as standalone course but as augmentation layer across curriculum
- Sustainability → Green coding principles, energy-aware profiling, carbon-aware computing modules
- Technical Writing → Docs-as-code, RFC-style proposals, API documentation, README-first development
- Version Control → Git history analysis, PR workflow simulations, merge conflict resolution drills
- Prototyping → Weekly sprint demos, MVP validation, user feedback loops
- Enterprise Integration → Microservices architecture, API gateways, legacy system interop patterns
- Ethics & Security → Threat modeling, privacy-by-design, bias auditing, secure SDLC

## Credit Allocation Targets
- Total Credits: 160
- Practice Component: ≥ 64 (40%+)
- Core Theory + Methods: 72
- Electives + Capstone: 24
