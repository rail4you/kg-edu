# Document Skill

This skill generates professional PPTX and DOCX documents using Python
libraries (python-pptx, python-docx). Tools are loaded dynamically via
ScriptToolFactory — no Elixir wrapper files needed.

## When to use

- User asks to create a PPT/PPTX presentation or slide deck
- User asks to create a DOCX document (teaching plan, lesson plan, syllabus)
- Content has been generated by the LLM and needs to be saved as a file

## Tools

- `generate_pptx(courseName, slides, author, outputDir)` — generates .pptx and returns file path
- `generate_docx(markdownContent, fileName, outputDir)` — generates .docx and returns file path
