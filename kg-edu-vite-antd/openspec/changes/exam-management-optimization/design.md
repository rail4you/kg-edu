## Context

当前考试管理系统存在以下问题：
1. 试卷列表页面缺少关联课程信息，无法按课程筛选考试
2. 考试创建时输入的时间和表格展示的时间格式不一致
3. 智能组卷功能无法按难度筛选习题
4. 题库管理中创建/编辑习题时没有难度选项
5. AI批改选择题时，答案正确但得分显示为0

## Goals / Non-Goals

**Goals:**
- 在试卷列表添加关联课程列，支持按课程、考试时间、截止时间筛选，支持按考试名称搜索
- 统一考试创建和展示的时间显示格式
- 智能组卷增加难度选择（1、2、3级）
- 题库管理创建/编辑习题时增加难度选项，导入默认难度为1
- 修复AI批改选择题的得分逻辑

**Non-Goals:**
- 不修改现有API接口结构（如果API已支持则前端直接使用）
- 不修改其他非相关的考试功能

## Decisions

### 1. 试卷列表筛选设计
- 使用现有的课程列表API获取课程选项
- 筛选使用前端筛选（如果数据量不大）或调用后端筛选API
- 搜索框使用防抖处理避免频繁请求

### 2. 时间格式统一
- 创建考试时使用 `YYYY-MM-DD HH:mm` 格式
- 表格展示也使用相同格式
- 确认数据库存储格式和时间处理库的使用方式

### 3. 难度字段设计
- 习题表已有 difficulty 字段（1、2、3）
- 前端使用下拉选择：简单(1)、中等(2)、困难(3)
- 导入时默认 difficulty = 1

### 4. AI批改选择题修复
- 检查选择题答案比对逻辑
- 确认答案格式（字符串比较、数组比较）
- 修复得分计算逻辑

## Risks / Trade-offs

- [风险] 如果后端API不支持课程筛选，可能需要扩展后端API → 协调后端开发
- [风险] 时间时区问题可能导致显示不一致 → 使用统一的时区处理
- [风险] AI批改逻辑可能在后端，需要前后端一起排查 → 确认AI批改的实现位置

## Migration Plan

1. 先实现试卷列表筛选（前端+后端API如需要）
2. 修复时间显示不一致问题
3. 添加题库难度选项
4. 实现智能组卷难度筛选
5. 修复AI批改选择题问题
