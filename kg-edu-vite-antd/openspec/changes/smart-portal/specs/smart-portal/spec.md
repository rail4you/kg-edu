## ADDED Requirements

### Requirement: 可配置的门户布局存储
系统 SHALL 以全局单条 JSON 配置存储智慧门户布局，由超级管理员维护、公开可读取，并在首次读取时写入默认布局。

#### Scenario: 首次读取自动种子
- **WHEN** 客户端首次调用 `GET /api/smart-portal/layout`
- **THEN** 系统在无记录时写入并返回默认布局（含课程列表 / 数据统计 / 图表 / 文本组件）

#### Scenario: 保存布局
- **WHEN** 超级管理员提交新的布局
- **THEN** 系统 upsert `key=default` 的记录并返回保存后的布局

#### Scenario: 非管理员写入被拒绝
- **WHEN** 非超级管理员调用 `PUT /api/smart-portal/layout`
- **THEN** 系统返回失败且不修改配置

### Requirement: 组件化与参数化
系统 SHALL 提供一组可配置的门户组件（Block），每个组件具有类型标识、标题、栅格宽度与私有参数，且参数可由管理端编辑。

#### Scenario: 组件面板展示可用组件
- **WHEN** 管理员打智慧门户编辑器
- **THEN** 系统展示组件面板，列出全部已注册组件类型（数据统计、图表、课程列表、知识点、轮播、文本、图片、视频、图标导航、表格、搜索条、日期、IP、地图、插件）

#### Scenario: 配置组件参数
- **WHEN** 管理员选中一个组件并修改其标题、宽度或私有参数
- **THEN** 系统更新该组件的 `config` 并即时反映在预览中

#### Scenario: 未知组件类型容错
- **WHEN** 布局中存在未注册的组件类型
- **THEN** 渲染器降级为占位提示而不报错崩溃

### Requirement: 拖放与分栏组合
系统 SHALL 允许管理员通过拖放新增与排序组件，并通过栅格宽度组合页面布局。

#### Scenario: 从组件面板添加组件
- **WHEN** 管理员从组件面板拖动或点击一个组件
- **THEN** 系统在画布中追加该组件的默认块

#### Scenario: 拖拽排序
- **WHEN** 管理员在画布中拖动组件到新位置
- **THEN** 系统更新组件顺序并保持其它组件参数不变

#### Scenario: 调整组件宽度
- **WHEN** 管理员修改组件栅格宽度
- **THEN** 渲染与预览按新的 12 栅格宽度布局，窄屏下自适应为整行

### Requirement: 租户动态数据与图表
系统 SHALL 使组件渲染当前访问者所在租户的动态内容，并能生成图表。

#### Scenario: 展示租户课程与计数
- **WHEN** 学生在租户上下文中打开智慧门户
- **THEN** 课程列表 / 数据统计组件展示该租户的课程与统计数字

#### Scenario: 知识点组件对接课程真实知识点
- **WHEN** 页面包含知识点组件
- **THEN** 组件展示该租户课程里的真实知识点（`knowledge_cell`），并标明其所属课程

#### Scenario: 图表渲染
- **WHEN** 页面包含图表组件
- **THEN** 系统用 echarts 按配置的图表类型与指标渲染，并在容器尺寸变化时自适应

#### Scenario: 单数据源失败隔离
- **WHEN** 某个数据源请求失败
- **THEN** 系统仅影响对应组件，其它组件仍正常渲染

#### Scenario: 搜索条过滤课程
- **WHEN** 用户在搜索条输入关键词
- **THEN** 同页课程列表（与知识点）实时按关键词过滤，至少可按课程名称/说明匹配

#### Scenario: IP 组件展示地址
- **WHEN** 页面包含 IP 组件
- **THEN** 系统优先后端接口获取调用方 IP 并展示具体值，外部服务不可用时仍展示一个数值

#### Scenario: 插件为只读演示
- **WHEN** 页面包含插件组件
- **THEN** 组件以只读演示形式展示，不提供跳转链接

### Requirement: 学生端展示
系统 SHALL 在学生端路由 `/dashboard/smart-portal` 渲染已保存的智慧门户布局。

#### Scenario: 学生打开智慧门户
- **WHEN** 已登录学生访问 `/dashboard/smart-portal`
- **THEN** 系统按保存的布局渲染门户页面

#### Scenario: 空布局
- **WHEN** 布局为空或加载失败
- **THEN** 系统展示友好空态而非报错

### Requirement: 管理端预览
系统 SHALL 在管理端编辑器中提供实时预览，可用选定租户的数据查看最终效果。

#### Scenario: 开启预览
- **WHEN** 管理员开启预览开关
- **THEN** 画布以只读方式渲染与客户端一致的最终效果

#### Scenario: 选择预览租户
- **WHEN** 管理员选择用于预览的租户
- **THEN** 预览中的动态组件使用该租户数据渲染

### Requirement: 学生端入口
系统 SHALL 在学生账户菜单与学生侧边导航提供「智能门户」入口。

#### Scenario: 账户菜单入口
- **WHEN** 学生打开账户菜单
- **THEN** 菜单中显示「智能门户」按钮，点击跳转 `/dashboard/smart-portal`

#### Scenario: 侧边导航入口
- **WHEN** 学生查看侧边导航「内容」分组
- **THEN** 显示「智能门户」导航项，点击跳转 `/dashboard/smart-portal`
