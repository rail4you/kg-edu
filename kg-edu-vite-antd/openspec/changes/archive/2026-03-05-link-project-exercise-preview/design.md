## Context

当前 `ExercisesTable` 组件在 `src/pages/teacher/knowledge-file.tsx` 中展示已关联到知识点的习题列表。用户需要点击习题卡片跳转到详情页面才能查看题目内容、答案和解析，这增加了操作步骤，降低了效率。教师在管理知识点与习题的关联时，需要快速浏览多个习题的内容以判断关联的准确性。

## Goals / Non-Goals

**Goals:**
- 实现鼠标悬停在习题卡片上时显示详情浮层
- 浮层包含题目内容、题目类型、答案、解析等信息
- 保持原有点击进入详情页的功能不变
- 浮层交互流畅，不影响页面性能

**Non-Goals:**
- 不修改后端 API 或数据结构
- 不改变习题列表的现有布局
- 不添加新的依赖库

## Decisions

1. **使用 Ant Design Popover 组件实现悬停预览**
   - 现有项目已使用 Ant Design，直接使用 Popover 组件可保持 UI 一致性
   - Popover 支持 hover 触发方式，配置简单

2. **浮层内容展示结构**
   - 题目内容（支持长文本省略）
   - 题目类型标签
   - AI 生成标签（如适用）
   - 答案和解析（如有）

3. **交互优化**
   - 悬停延迟设置为 200ms，避免误触发
   - 浮层添加阴影和圆角，与现有卡片风格一致
   - 浮层最大高度设置滚动条，适应长内容

## Risks / Trade-offs

- [风险] 悬停预览可能与取消关联按钮的点击操作冲突 → 浮层设置 pointer-events: none，按钮区域不受影响
- [风险] 长题目内容可能导致浮层过大 → 设置最大高度并启用滚动
