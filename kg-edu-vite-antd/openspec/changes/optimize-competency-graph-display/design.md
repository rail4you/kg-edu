## Context

能力图谱是教师管理教学能力结构的核心功能，当前实现中：
1. 图谱节点点击只显示基本信息（ID、名称），无法查看关联的学习资源
2. 能力管理表格中描述字段无截断处理，长文本破坏布局
3. 图谱节点 tooltip 只显示名称和类别，缺少描述信息

现有课程图谱中已有成熟的资源展示组件 `KnowledgeResourcePanel`，支持展示文件、视频、习题、作业等资源。

## Goals / Non-Goals

**Goals:**
- 实现能力节点点击后显示侧边面板，展示关联的文件、视频、习题等资源
- 表格描述列实现文本截断和悬停 tooltip
- 图谱节点 tooltip 显示完整描述信息

**Non-Goals:**
- 不修改后端数据模型和 API 接口
- 不修改学生端能力图谱页面（仅教师端）
- 不添加新的资源类型支持

## Decisions

### 1. 复用 KnowledgeResourcePanel 组件
- **决策**: 复用 `src/components/KnowledgeResourcePanel.tsx` 组件展示关联资源
- **理由**: 该组件已实现完整的资源列表展示、文件预览、视频播放、习题作答等功能，无需重复开发
- **替代方案**: 从零开发新的资源展示组件（成本高，不推荐）

### 2. 能力节点关联资源的获取方式
- **决策**: 能力节点关联的资源通过关联的知识点间接获取
- **理由**: 当前数据模型中，子能力通过知识点建立关联，资源存储在知识点层面。需要先获取能力关联的知识点，再获取知识点关联的资源
- **替代方案**: 直接在能力层面存储资源关联（需要后端改造，暂不涉及）

### 3. 表格描述截断使用 Ant Design Typography
- **决策**: 使用 Ant Design 的 `Typography.Text` 组件的 `ellipsis` 属性
- **理由**: 原生支持文本截断和 tooltip，样式与现有 UI 一致
- **替代方案**: CSS 手动控制（需要额外样式处理）

## Risks / Trade-offs

- [风险] 能力节点可能无关联知识点时，资源面板显示为空 → 提示用户先关联知识点
- [风险] 大量资源时面板加载性能 → 已有分页和懒加载机制，需关注
- [权衡] 资源展示逻辑复用课程图谱实现，可能存在细微交互差异 → 保持一致性优先
